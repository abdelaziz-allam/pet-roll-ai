# Inicio Rapido: Admin

Bienvenido al Portal de Administracion de Petfolioo. Como Admin, tienes amplio acceso operativo para gestionar usuarios, mascotas, contenido y las actividades diarias de la plataforma. Esta guia cubre lo que puedes hacer, tu flujo de trabajo diario y cuando escalar a un Super Admin.

## Primeros Pasos Despues de Recibir Acceso

1. **Inicia sesion y verifica tu perfil** - Haz clic en tu avatar en la esquina superior derecha para confirmar que tu nombre y correo electronico son correctos.
2. **Explora el Dashboard** - Comprende el estado actual de la plataforma: usuarios activos, verificaciones pendientes, actividad reciente.
3. **Revisa la cola de Verification** - Verifica si hay verificaciones de criadores o mascotas pendientes de accion.
4. **Navega App Users** - Ordena por fecha de registro reciente para ver nuevos registros y familiarizarte con la base de usuarios.
5. **Revisa Feedback** - Verifica si hay quejas abiertas de usuarios que necesiten respuesta.

## Responsabilidades Clave

### Operaciones
Eres el operador principal de la plataforma. Las revisiones de verificacion, la moderacion de Mating y la gestion de usuarios son tus tareas diarias principales. Mantiene la cola de verificacion con menos de 24 horas de antiguedad siempre que sea posible.

### Gestion de Contenido
Gestionas el Blog, las Pet Categories y los datos de mascotas. Asegurate de que las publicaciones del blog sean precisas, las categorias reflejen las especies soportadas y los perfiles de mascotas tengan informacion correcta.

### Soporte al Usuario
Cuando los usuarios de la app reportan problemas a traves de Feedback, eres responsable de responder. Puedes editar cuentas de usuario, bloquear usuarios abusivos y corregir datos de mascotas en su nombre.

### Gestion de Notificaciones
Puedes enviar notificaciones a toda la plataforma o dirigidas. Usa esto para ventanas de mantenimiento, anuncios de funcionalidades o cambios importantes en las politicas.

| Accion | Quien Puede |
|--------|-------------|

| Export datos de usuario | Solo Super Admin |
| Delete notificaciones | Solo Super Admin |
| Acceder o editar Settings | Solo Super Admin |
| Create/Edit/Delete cuentas de administrador | Solo Super Admin |
| Manage Permissions de roles | Solo Super Admin |

## Cuando Escalar

Contacta a tu Super Admin cuando necesites:

- Eliminar una cuenta de usuario permanentemente (puedes bloquear, pero no eliminar)
- Exportar datos de usuarios para solicitudes de cumplimiento o legales
- Cambiar configuraciones de la plataforma o feature flags
- Otorgar acceso de administrador a un nuevo miembro del equipo
- Eliminar una notificacion que fue enviada por error
- Manejar un incidente de seguridad que requiera cambios a nivel de sistema
