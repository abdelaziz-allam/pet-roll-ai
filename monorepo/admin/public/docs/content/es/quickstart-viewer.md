# Inicio Rapido: Viewer

Bienvenido al Portal de Administracion de Petfolioo. Como Viewer, tienes acceso de solo lectura a la mayoria de las paginas de la plataforma. Tu rol proporciona visibilidad de las operaciones de la plataforma sin la capacidad de modificar datos. Esta guia cubre lo que puedes ver, como usar el portal de manera efectiva y como solicitar acceso elevado si es necesario.

---

## Que Significa "Solo Lectura" en la Practica

Tu interfaz esta simplificada en comparacion con otros roles:

| Elemento de UI | Lo Que Ves |
|----------------|------------|
| Botones Create/Add | Ocultos - no visibles en ninguna parte |
| Botones Edit | Ocultos - las filas de tabla no son clicables para edicion |
| Opciones Delete | Ocultas - sin menus de accion con opciones destructivas |
| Botones Approve/Reject | Ocultos - estado de verificacion mostrado como texto de solo lectura |
| Boton Send Notification | Oculto |
| Botones Export | Ocultos |
| Botones Ban/Unban | Ocultos |

Ves los mismos datos que otros roles, pero la interfaz elimina todos los controles de accion. Esto significa que no puedes modificar nada accidentalmente. Tablas, graficos, vistas de detalle e indicadores de estado se muestran normalmente.

## Primeros Pasos Despues de Recibir Acceso

1. **Inicia sesion y verifica tu perfil** - Haz clic en tu avatar para confirmar los detalles de tu cuenta.
2. **Explora el Dashboard** - Esta es tu base principal. Estudia las tarjetas de KPI y los graficos de analiticas para entender el estado de la plataforma de un vistazo.
3. **Visita Analytics** - Revisa tendencias de engagement, metricas de crecimiento y patrones de uso de la plataforma.
4. **Navega App Users y Pets** - Familiarizate con los datos disponibles para tus necesidades de reportes.
5. **Revisa Verification** - Comprende el estado de la cola y la tasa de aprobacion para evaluar la carga operativa.

## Responsabilidades Clave

### Supervision
Tu valor principal es la supervision informada. Puedes ver el panorama completo de las operaciones de la plataforma sin necesidad de tomar accion. Usa esto para identificar tendencias, detectar problemas potenciales tempranamente y mantener informados a los interesados.

### Reportes
Aunque no puedes exportar datos directamente desde el portal, puedes usar lo que ves para preparar reportes externamente. Las paginas de Dashboard y Analytics proporcionan las metricas mas comunmente necesarias para actualizaciones a interesados.

### Monitoreo
Observa patrones inusuales: caidas repentinas en aprobaciones de verificacion, picos en bloqueos de usuarios o metricas de engagement en declive. Cuando detectes algo preocupante, plantealo con un Admin o Super Admin que pueda investigar y actuar.

### Visibilidad para Interesados
Si eres un interesado del negocio, inversor o socio, el rol Viewer te brinda transparencia sobre las operaciones de la plataforma sin requerir que el equipo prepare reportes separados para ti.

## Preparar Reportes desde Acceso de Solo Lectura

Ya que no puedes exportar datos directamente, aqui hay enfoques efectivos:

1. **Capturas de pantalla** - Captura graficos del Dashboard y Analytics para presentaciones.
2. **Notas manuales** - Registra metricas clave de las tarjetas de KPI durante tu revision diaria.
3. **Solicita exportaciones** - Pide a un Admin o Super Admin que exporte los datos que necesitas para un analisis mas profundo.
4. **Revisiones programadas** - Establece un horario recurrente para revisar el portal y anotar cambios semana a semana.

---

## Como Solicitar Acceso Elevado

Si tus responsabilidades cambian y necesitas la capacidad de tomar acciones (aprobar verificaciones, moderar contenido, gestionar usuarios), sigue este proceso:

1. Identifica que acciones especificas necesitas y por que.
2. Contacta al Super Admin de tu organizacion con tu solicitud.
3. Especifica si necesitas una mejora de rol (a Moderator o Admin) o solo permisos adicionales especificos.
4. El Super Admin puede personalizar tus permisos sin cambiar la etiqueta de tu rol si solo necesitas algunas acciones adicionales.
