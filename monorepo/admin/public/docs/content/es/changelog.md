# Novedades

Mantente al dia con las ultimas mejoras del Portal de Administracion de Petfolioo.

---

## Julio 2026

### Documentacion de Permisos Basados en Roles
- Se agrego una guia completa de Roles y Permisos
- Todas las paginas de documentacion ahora muestran que roles pueden acceder a cada funcionalidad
- Se agregaron guias de inicio rapido especificas por rol para cada tipo de usuario

### Mejoras en la Documentacion
- Se agregaron diagramas de flujo de trabajo para procesos clave
- Se agrego un glosario de terminos de la plataforma
- Se agrego una guia de solucion de problemas
- Exportacion a Print/PDF ahora disponible para toda la documentacion
- Busqueda de texto completo en todos los articulos

---

## Junio 2026

### Lanzamiento del Manual de Usuario
- Manual de usuario completo con 16 articulos que cubren todas las funciones del portal de administracion
- Capturas de pantalla de cada pagina
- Soporte multiidioma (12 idiomas)
- Busqueda del lado del cliente con resultados instantaneos

---

## Mayo 2026

### Funcionalidades de la Plataforma
- Dashboard de Vaccination Analytics con visualizacion de tendencias y desglose por especie
- Modulo de Health Certifications para cargar y validar documentos veterinarios
- Lanzamiento del Mating Marketplace conectando criadores verificados
- Flujo de trabajo de Breeder Verification con cola de revision de documentos
- Sistema de notificaciones push para mensajes dirigidos y masivos

### Mejoras del Portal de Administracion
- Funcionalidad de Export para todas las tablas de datos (formatos CSV y PDF)
- Filtrado y busqueda mejorados en el Pet Registry
- Acciones masivas para gestion de usuarios (ban, unban, notify)

---

## Abril 2026

### Infraestructura
- Se migro el alojamiento del Portal de Administracion a Google Cloud Run para mejor escalabilidad
- Se redujo el tiempo promedio de carga de pagina en un 40%
- Se agrego timeout automatico de sesion con reautenticacion segura

### Gestion de Usuarios
- Nueva pagina de gestion de Feedback con respuestas enlazadas
- Vista detallada del perfil de App User con linea de tiempo de actividad
- Registro de historial de bloqueos con seguimiento de motivos

---

## Marzo 2026

### Plataforma Principal
- Lanzamiento inicial del Portal de Administracion con Dashboard, Pet Registry y Gestion de Usuarios
- Control de Acceso Basado en Roles (RBAC) con cuatro roles: Super Admin, Admin, Moderator, Viewer
- Sistema de gestion de Blog con editor de texto enriquecido
- Gestion de categorias para mascotas y contenido
- Panel de Settings para configuracion de la plataforma
