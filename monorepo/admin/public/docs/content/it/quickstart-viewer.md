# Guida Rapida: Viewer

Benvenuto nel Portale di Amministrazione di Petfolioo. Come Viewer, hai accesso in sola lettura alla maggior parte delle pagine della piattaforma. Il tuo ruolo fornisce visibilita sulle operazioni della piattaforma senza la possibilita di modificare dati. Questa guida copre cosa puoi vedere, come usare il portale efficacemente e come richiedere accesso elevato se necessario.

---

## Pagine Disponibili

| Pagina | Livello di Accesso |
|--------|-------------------|
| Dashboard | View KPI e grafici analitici |
| App Users | View lista utenti e profili |
| Pets | View registro animali e profili |
| Pet Categories | View tassonomia categorie |
| Verification | View coda e stato delle richieste |
| Mating | View annunci del marketplace |
| Health Certs | View registri di certificazione |
| Vax Analytics | View dati vaccinazioni |
| Feedback | View segnalazioni utenti |
| Blog | View post pubblicati |
| Notifications | View notifiche inviate |
| Analytics | View grafici e metriche |

Pagine **non** presenti nella tua barra laterale: Admin Users, Settings.

---

## Cosa Significa "Solo Lettura" in Pratica

La tua interfaccia e semplificata rispetto agli altri ruoli:

| Elemento UI | Cosa Vedi |
|-------------|-----------|
| Pulsanti Create/Add | Nascosti - non visibili da nessuna parte |
| Pulsanti Edit | Nascosti - le righe della tabella non sono cliccabili per la modifica |
| Opzioni Delete | Nascoste - nessun menu azione con opzioni distruttive |
| Pulsanti Approve/Reject | Nascosti - stato della verifica mostrato come testo in sola lettura |
| Pulsante Send Notification | Nascosto |
| Pulsanti Export | Nascosti |
| Pulsanti Ban/Unban | Nascosti |

Vedi gli stessi dati degli altri ruoli, ma l'interfaccia rimuove tutti i controlli di azione. Questo significa che non puoi modificare nulla accidentalmente. Tabelle, grafici, viste di dettaglio e indicatori di stato vengono visualizzati normalmente.

## Primi Passi Dopo Aver Ricevuto l'Accesso

1. **Accedi e verifica il tuo profilo** - Clicca sul tuo avatar per confermare i dettagli del tuo account.
2. **Esplora il Dashboard** - Questa e la tua base principale. Studia le schede KPI e i grafici analitici per capire lo stato della piattaforma a colpo d'occhio.
3. **Visita Analytics** - Rivedi le tendenze di engagement, le metriche di crescita e i pattern di utilizzo della piattaforma.
4. **Sfoglia App Users e Pets** - Familiarizza con i dati disponibili per le tue esigenze di reportistica.
5. **Controlla Verification** - Comprendi lo stato della coda e il tasso di approvazione per valutare il carico operativo.

## Responsabilita Chiave

### Supervisione
Il tuo valore principale e la supervisione informata. Puoi vedere il quadro completo delle operazioni della piattaforma senza bisogno di agire. Usa questo per identificare tendenze, individuare potenziali problemi in anticipo e mantenere informati gli stakeholder.

### Reportistica
Sebbene non possa esportare dati direttamente dal portale, puoi usare cio che vedi per preparare report esternamente. Le pagine Dashboard e Analytics forniscono le metriche piu comunemente necessarie per aggiornamenti agli stakeholder.

### Monitoraggio
Osserva pattern insoliti: cali improvvisi nelle approvazioni delle verifiche, picchi nei blocchi utente o metriche di engagement in declino. Quando noti qualcosa di preoccupante, segnalalo a un Admin o Super Admin che puo indagare e agire.

### Visibilita per gli Stakeholder
Se sei uno stakeholder aziendale, investitore o partner, il ruolo Viewer ti offre trasparenza sulle operazioni della piattaforma senza richiedere al team di preparare report separati per te.

## Preparare Report dall'Accesso in Sola Lettura

Dato che non puoi esportare dati direttamente, ecco approcci efficaci:

1. **Screenshot** - Cattura i grafici del Dashboard e Analytics per le presentazioni.
2. **Note manuali** - Registra le metriche chiave dalle schede KPI durante la tua revisione quotidiana.
3. **Richiedi esportazioni** - Chiedi a un Admin o Super Admin di esportare i dati necessari per un'analisi approfondita.
4. **Revisioni programmate** - Stabilisci un orario ricorrente per rivedere il portale e annotare i cambiamenti settimana dopo settimana.

---

## Come Richiedere Accesso Elevato

Se le tue responsabilita cambiano e hai bisogno della capacita di eseguire azioni (approvare verifiche, moderare contenuti, gestire utenti), segui questo processo:

1. Identifica quali azioni specifiche ti servono e perche.
2. Contatta il Super Admin della tua organizzazione con la tua richiesta.
3. Specifica se hai bisogno di un upgrade del ruolo (a Moderator o Admin) o solo di permessi aggiuntivi specifici.
4. Il Super Admin puo personalizzare i tuoi permessi senza cambiare l'etichetta del tuo ruolo se servono solo poche azioni aggiuntive.
