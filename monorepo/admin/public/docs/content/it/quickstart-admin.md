# Guida Rapida: Admin

Benvenuto nel Portale di Amministrazione di Petfolioo. Come Admin, hai un ampio accesso operativo per gestire utenti, animali, contenuti e le attivita quotidiane della piattaforma. Questa guida copre cosa puoi fare, il tuo flusso di lavoro quotidiano e quando escalare a un Super Admin.

## Primi Passi Dopo Aver Ricevuto l'Accesso

1. **Accedi e verifica il tuo profilo** - Clicca sul tuo avatar in alto a destra per confermare che nome e email siano corretti.
2. **Esplora il Dashboard** - Comprendi lo stato attuale della piattaforma: utenti attivi, verifiche in sospeso, attivita recente.
3. **Controlla la coda di Verification** - Verifica se ci sono verifiche di allevatori o animali in attesa di azione.
4. **Sfoglia App Users** - Ordina per data di registrazione recente per vedere le nuove iscrizioni e familiarizzare con la base utenti.
5. **Rivedi Feedback** - Controlla se ci sono reclami aperti degli utenti che necessitano di risposta.

---

## Checklist delle Attivita Quotidiane

- [ ] Apri il Dashboard e controlla le schede KPI per qualsiasi anomalia
- [ ] Processa gli elementi in sospeso nella coda di Verification (approva o rifiuta con motivazione)
- [ ] Controlla gli annunci di Mating per nuove voci o voci segnalate che richiedono moderazione
- [ ] Rivedi le segnalazioni di Feedback e rispondi ai problemi urgenti
- [ ] Monitora App Users per account che necessitano blocco o indagine
- [ ] Controlla Health Certs per revisioni di certificazione in sospeso
- [ ] Invia notifiche della piattaforma se ci sono annunci o finestre di manutenzione
- [ ] Rivedi Analytics per tendenze di engagement ed esporta report secondo necessita

## Responsabilita Chiave

### Operazioni
Sei l'operatore principale della piattaforma. Le revisioni delle verifiche, la moderazione di Mating e la gestione utenti sono le tue attivita quotidiane principali. Mantieni la coda di verifica con meno di 24 ore di anzianita quando possibile.

### Gestione dei Contenuti
Gestisci il Blog, le Pet Categories e i dati degli animali. Assicurati che i post del blog siano accurati, le categorie riflettano le specie supportate e i profili degli animali abbiano informazioni corrette.

### Supporto Utenti
Quando gli utenti dell'app segnalano problemi tramite Feedback, sei responsabile della risposta. Puoi modificare account utente, bloccare utenti abusivi e correggere dati degli animali per loro conto.

### Gestione Notifiche
Puoi inviare notifiche a tutta la piattaforma o mirate. Usa questa funzione per finestre di manutenzione, annunci di funzionalita o importanti modifiche alle policy.

## Cosa Non Puoi Fare

| Azione | Chi Puo |
|--------|---------|
| Delete utenti dell'app | Solo Super Admin |
| Export dati utente | Solo Super Admin |
| Delete notifiche | Solo Super Admin |
| Accedere o modificare Settings | Solo Super Admin |
| Create/Edit/Delete account amministratore | Solo Super Admin |
| Manage Permissions dei ruoli | Solo Super Admin |

---

## Quando Escalare

Contatta il tuo Super Admin quando hai bisogno di:

- Rimuovere permanentemente un account utente (puoi bloccare, ma non eliminare)
- Esportare dati utente per richieste di conformita o legali
- Modificare impostazioni della piattaforma o feature flag
- Concedere accesso amministratore a un nuovo membro del team
- Eliminare una notifica inviata per errore
- Gestire un incidente di sicurezza che richiede modifiche a livello di sistema
