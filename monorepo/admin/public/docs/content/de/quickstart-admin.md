# Schnellstart: Admin

Willkommen im Petfolioo Admin-Portal. Als Admin haben Sie umfassenden operativen Zugriff zur Verwaltung von Benutzern, Haustieren, Inhalten und taeglichen Plattformaktivitaeten. Dieser Leitfaden behandelt, was Sie tun koennen, Ihren taeglichen Arbeitsablauf und wann Sie an einen Super Admin eskalieren sollten.

## Erste Schritte nach Zugriffsvergabe

1. **Anmelden und Profil ueberpruefen** - Klicken Sie auf Ihren Avatar oben rechts, um Ihren Namen und Ihre E-Mail-Adresse zu bestaetigen.
2. **Dashboard erkunden** - Verstehen Sie den aktuellen Zustand der Plattform: aktive Benutzer, ausstehende Verifizierungen, letzte Aktivitaeten.
3. **Verifizierungswarteschlange pruefen** - Sehen Sie nach, ob ausstehende Zuechter- oder Haustierverifizierungen auf Bearbeitung warten.
4. **App-Benutzer durchsehen** - Sortieren Sie nach dem letzten Beitrittsdatum, um neue Registrierungen zu sehen und sich mit der Benutzerbasis vertraut zu machen.
5. **Feedback ueberpruefen** - Pruefen Sie, ob offene Benutzerbeschwerden vorhanden sind, die eine Antwort erfordern.

---

## Taegliche Arbeitsablauf-Checkliste

- [ ] Dashboard oeffnen und KPI-Karten auf Auffaelligkeiten pruefen
- [ ] Ausstehende Eintraege in der Verifizierungswarteschlange bearbeiten (mit Begruendung genehmigen oder ablehnen)
- [ ] Paarungsanzeigen auf neue oder markierte Eintraege pruefen, die Moderation erfordern
- [ ] Feedback-Eingaben ueberpruefen und auf dringende Probleme reagieren
- [ ] App-Benutzer auf Konten ueberwachen, die gesperrt oder untersucht werden muessen
- [ ] Gesundheitszertifikate auf ausstehende Zertifizierungspruefungen pruefen
- [ ] Plattformbenachrichtigungen senden, falls Ankuendigungen oder Wartungsfenster anstehen
- [ ] Analysen auf Engagement-Trends pruefen und bei Bedarf Berichte exportieren

---

## Hauptverantwortlichkeiten

### Betrieb
Sie sind der primaere Betreiber der Plattform. Verifizierungspruefungen, Paarungsmoderation und Benutzerverwaltung sind Ihre taeglichen Kernaufgaben. Halten Sie die Verifizierungswarteschlange moeglichst unter 24 Stunden.

### Inhaltsverwaltung
Sie verwalten den Blog, die Haustierkategorien und Haustierdaten. Stellen Sie sicher, dass Blogbeitraege korrekt sind, Kategorien die unterstuetzten Arten widerspiegeln und Haustierprofile korrekte Informationen enthalten.

### Benutzersupport
Wenn App-Benutzer Probleme ueber Feedback melden, sind Sie fuer die Beantwortung verantwortlich. Sie koennen Benutzerkonten bearbeiten, missbraeuchliche Benutzer sperren und Haustierdaten in deren Auftrag korrigieren.

### Benachrichtigungsverwaltung
Sie koennen plattformweite oder gezielte Benachrichtigungen senden. Nutzen Sie diese fuer Wartungsfenster, Funktionsankuendigungen oder wichtige Richtlinienaenderungen.

---

## Was Sie nicht tun koennen

| Aktion | Wer kann |
|--------|----------|
| App-Benutzer loeschen | Nur Super Admin |
| Benutzerdaten exportieren | Nur Super Admin |
| Benachrichtigungen loeschen | Nur Super Admin |
| Einstellungen aufrufen oder bearbeiten | Nur Super Admin |
| Admin-Konten erstellen/bearbeiten/loeschen | Nur Super Admin |
| Rollenberechtigungen verwalten | Nur Super Admin |

---

## Wann Sie eskalieren sollten

Kontaktieren Sie Ihren Super Admin, wenn Sie Folgendes benoetigen:

- Ein Benutzerkonto dauerhaft entfernen (Sie koennen sperren, aber nicht loeschen)
- Benutzerdaten fuer Compliance- oder Rechtsanfragen exportieren
- Plattformeinstellungen oder Feature-Flags aendern
- Einem neuen Teammitglied Admin-Zugriff gewaehren
- Eine versehentlich gesendete Benachrichtigung loeschen
- Einen Sicherheitsvorfall bearbeiten, der systemweite Aenderungen erfordert
