# Schnellstart: Viewer

Willkommen im Petfolioo Admin-Portal. Als Viewer haben Sie schreibgeschuetzten Zugriff auf die meisten Plattformseiten. Ihre Rolle bietet Einblick in den Plattformbetrieb, ohne die Moeglichkeit, Daten zu aendern. Dieser Leitfaden behandelt, was Sie sehen koennen, wie Sie das Portal effektiv nutzen und wie Sie bei Bedarf erweiterten Zugriff anfordern koennen.

---

## Verfuegbare Seiten

| Seite | Zugriffsebene |
|-------|---------------|
| Dashboard | View KPIs und Analysediagramme |
| App-Benutzer | View Benutzerliste und Profile |
| Haustiere | View Haustierregister und Profile |
| Haustierkategorien | View Kategorietaxonomie |
| Verifizierung | View Warteschlange und Einreichungsstatus |
| Paarung | View Marktplatzanzeigen |
| Gesundheitszertifikate | View Zertifizierungsdatensaetze |
| Impfanalysen | View Impfdaten |
| Feedback | View Benutzereingaben |
| Blog | View veroeffentlichte Beitraege |
| Benachrichtigungen | View gesendete Benachrichtigungen |
| Analysen | View Diagramme und Metriken |

Seiten, die **nicht** in Ihrer Seitenleiste erscheinen: Admin-Benutzer, Einstellungen.

---

## Was "Nur Ansicht" praktisch bedeutet

Ihre Oberflaeche ist im Vergleich zu anderen Rollen vereinfacht:

| UI-Element | Was Sie sehen |
|------------|---------------|
| Create/Add-Buttons | Ausgeblendet - nirgendwo sichtbar |
| Edit-Buttons | Ausgeblendet - Tabellenzeilen sind nicht zum Bearbeiten anklickbar |
| Delete-Optionen | Ausgeblendet - keine Aktionsmenues mit destruktiven Optionen |
| Approve/Reject-Buttons | Ausgeblendet - Verifizierungsstatus wird als schreibgeschuetzter Text angezeigt |
| Send Notification-Button | Ausgeblendet |
| Export-Buttons | Ausgeblendet |
| Ban/Unban-Buttons | Ausgeblendet |

Sie sehen die gleichen Daten wie andere Rollen, aber die Oberflaeche entfernt alle Aktionssteuerungen. Das bedeutet, dass Sie versehentlich nichts aendern koennen. Tabellen, Diagramme, Detailansichten und Statusanzeigen werden normal dargestellt.

---

## Erste Schritte nach Zugriffsvergabe

1. **Anmelden und Profil ueberpruefen** - Klicken Sie auf Ihren Avatar, um Ihre Kontodaten zu bestaetigen.
2. **Dashboard erkunden** - Dies ist Ihre Startseite. Studieren Sie die KPI-Karten und Analysediagramme, um den Plattformzustand auf einen Blick zu verstehen.
3. **Analysen besuchen** - Ueberpruefen Sie Engagement-Trends, Wachstumsmetriken und Plattformnutzungsmuster.
4. **App-Benutzer und Haustiere durchsehen** - Machen Sie sich mit den verfuegbaren Daten fuer Ihre Berichtsanforderungen vertraut.
5. **Verifizierung pruefen** - Verstehen Sie den Warteschlangenstatus und die Genehmigungsrate, um die operative Belastung einzuschaetzen.

## Taegliche Arbeitsablauf-Checkliste

- [ ] Dashboard auf Plattformzustandsmetriken und KPI-Aenderungen ueberpruefen
- [ ] Analysen auf Benutzerwachstumstrends und Engagement-Muster pruefen
- [ ] Laenge der Verifizierungswarteschlange ueberwachen, um die Teamauslastung zu bewerten
- [ ] Feedback-Eingaben ueberpruefen, um die Benutzerstimmung einzuschaetzen
- [ ] Aktuelle Paarungsanzeigen durchsehen, um die Marktplatzaktivitaet zu verstehen
- [ ] Benachrichtigungsverlauf pruefen, um ueber Plattformkommunikation informiert zu bleiben
- [ ] Auffaelligkeiten oder Bedenken notieren, um sie mit Ihrem Admin oder Super Admin zu besprechen

## Hauptverantwortlichkeiten

### Aufsicht
Ihr primaerer Wert ist informierte Aufsicht. Sie koennen das vollstaendige Bild des Plattformbetriebs sehen, ohne handeln zu muessen. Nutzen Sie dies, um Trends zu erkennen, potenzielle Probleme fruehzeitig zu identifizieren und Stakeholder informiert zu halten.

### Berichterstattung
Obwohl Sie Daten nicht direkt aus dem Portal exportieren koennen, koennen Sie das Gesehene nutzen, um extern Berichte zu erstellen. Die Dashboard- und Analyseseiten liefern die Metriken, die am haeufigsten fuer Stakeholder-Updates benoetigt werden.

### Ueberwachung
Achten Sie auf ungewoehnliche Muster: ploetzliche Rueckgaenge bei Verifizierungsgenehmigungen, Spitzen bei Benutzersperrungen oder sinkende Engagement-Metriken. Wenn Sie etwas Besorgniserregendes bemerken, bringen Sie es bei einem Admin oder Super Admin zur Sprache, der untersuchen und handeln kann.

### Stakeholder-Transparenz
Wenn Sie ein Geschaeftsbeteiligter, Investor oder Partner sind, bietet Ihnen die Viewer-Rolle Transparenz ueber den Plattformbetrieb, ohne dass das Team separate Berichte fuer Sie erstellen muss.

---

## Berichte aus dem Nur-Ansicht-Zugriff erstellen

Da Sie Daten nicht direkt exportieren koennen, hier einige effektive Ansaetze:

1. **Screenshots** - Erfassen Sie Dashboard- und Analysediagramme fuer Praesentationen.
2. **Manuelle Notizen** - Notieren Sie Schluesselmetriken von KPI-Karten waehrend Ihrer taeglichen Ueberpruefung.
3. **Exporte anfordern** - Bitten Sie einen Admin oder Super Admin, Daten zu exportieren, die Sie fuer tiefergehende Analysen benoetigen.
4. **Geplante Ueberpruefungen** - Legen Sie einen wiederkehrenden Zeitpunkt fest, um das Portal zu ueberpruefen und Aenderungen von Woche zu Woche zu notieren.

---

## Erweiterten Zugriff anfordern

Wenn sich Ihre Verantwortlichkeiten aendern und Sie die Moeglichkeit benoetigen, Aktionen durchzufuehren (Verifizierungen genehmigen, Inhalte moderieren, Benutzer verwalten), folgen Sie diesem Prozess:

1. Identifizieren Sie, welche spezifischen Aktionen Sie benoetigen und warum.
2. Kontaktieren Sie den Super Admin Ihrer Organisation mit Ihrer Anfrage.
3. Geben Sie an, ob Sie ein Rollen-Upgrade (zu Moderator oder Admin) oder nur bestimmte zusaetzliche Berechtigungen benoetigen.
4. Der Super Admin kann Ihre Berechtigungen anpassen, ohne Ihre Rollenbezeichnung zu aendern, wenn nur wenige zusaetzliche Aktionen erforderlich sind.
