# Schnellstart: Moderator

Willkommen im Petfolioo Admin-Portal. Als Moderator liegt Ihr Fokus auf Inhaltsqualitaet und Gemeinschaftssicherheit. Sie ueberpruefen Verifizierungen, moderieren Anzeigen und stellen sicher, dass Haustierdaten korrekt sind. Dieser Leitfaden behandelt Ihren Zugriff, taegliche Arbeitsablaeufe und Grenzen.

## Erste Schritte nach Zugriffsvergabe

1. **Anmelden und Profil pruefen** - Klicken Sie auf Ihren Avatar, um zu bestaetigen, dass Ihre Daten korrekt sind.
2. **Verifizierungswarteschlange oeffnen** - Dies ist Ihr primaerer Arbeitsbereich. Sehen Sie, was zur Ueberpruefung ansteht.
3. **Paarungsseite durchsehen** - Machen Sie sich mit aktiven Anzeigen und den verfuegbaren Moderationstools vertraut.
4. **Haustiere erkunden** - Klicken Sie auf einige Haustierprofile, um die Datenstruktur und die bearbeitbaren Felder zu verstehen.
5. **Dashboard ueberpruefen** - Gewinnen Sie ein grundlegendes Verstaendnis des Plattformaktivitaetsniveaus.

---

## Taegliche Arbeitsablauf-Checkliste

- [ ] Dashboard fuer einen schnellen Zustandsueberblick pruefen
- [ ] Verifizierungswarteschlange bearbeiten: Dokumente ueberpruefen, legitime Zuechter genehmigen, unvollstaendige oder betruegerische Einreichungen mit klarer Begruendung ablehnen
- [ ] Paarungsanzeigen moderieren: unangemessene Inhalte markieren oder entfernen, Anzeigengenauigkeit ueberpruefen
- [ ] Haustiere auf gemeldete oder markierte Profile ueberpruefen und ungenaue Daten korrigieren
- [ ] Gesundheitszertifikate auf ausstehende Zertifizierungspruefungen pruefen
- [ ] Problematische Benutzer sperren, die gegen Gemeinschaftsrichtlinien verstossen
- [ ] Feedback auf Benutzerberichte ueber Inhaltsprobleme durchsehen (auch wenn Sie nicht antworten koennen, koennen Sie auf das Gelesene reagieren)

---

## Hauptverantwortlichkeiten

### Verifizierungspruefungen
Ihre wichtigste Aufgabe. Zuechter reichen Unterlagen ein, um ihre Legitimation und Qualifikation nachzuweisen. Sie ueberpruefen diese Dokumente auf Echtheit, Vollstaendigkeit und Konformitaet mit den Plattformstandards. Genehmigen Sie legitime Antraege zeitnah und lehnen Sie betruegerische mit einer klaren Erklaerung ab.

### Paarungsmoderation
Ueberwachen Sie die Anzeigen im Paarungsmarktplatz auf unangemessene Inhalte, irrefuehrende Beschreibungen oder Richtlinienverstoesse. Verwenden Sie die Moderate-Aktion, um problematische Anzeigen zu markieren oder auszublenden.

### Haustierdatenqualitaet
Sie koennen Haustierprofile bearbeiten, um falsche Rasseinformationen zu korrigieren, Tippfehler zu beheben, den Gesundheitsstatus zu aktualisieren oder unangemessene Fotos zu entfernen. Halten Sie das Haustierregister genau und vertrauenswuerdig.

### Gemeinschaftssicherheit
Sie koennen Benutzer sperren, die gegen Plattformrichtlinien verstossen. Nutzen Sie dies fuer Spam-Konten, missbraeuchliches Verhalten oder Benutzer, die wiederholt betruegerische Verifizierungen einreichen.

### Gesundheitszertifizierungspruefung
Ueberpruefen Sie eingereichte Gesundheitszertifizierungen auf Richtigkeit und genehmigen oder lehnen Sie sie basierend auf der bereitgestellten Dokumentation ab.

## Was Sie nicht tun koennen

| Aktion | Wer kann |
|--------|----------|
| App-Benutzer erstellen oder bearbeiten | Admin oder Super Admin |
| Haustiere loeschen | Admin oder Super Admin |
| Paarungsanzeigen bearbeiten oder loeschen | Admin oder Super Admin |
| Benachrichtigungen senden | Admin oder Super Admin |
| Auf Feedback antworten | Admin oder Super Admin |
| Blogbeitraege erstellen oder bearbeiten | Admin oder Super Admin |
| Analysen anzeigen oder exportieren | Admin oder Super Admin |
| Admin-Benutzer aufrufen | Nur Super Admin |
| Einstellungen aufrufen | Nur Super Admin |
| Daten exportieren | Admin oder Super Admin |
| Etwas loeschen | Admin oder Super Admin |

---

## Wann Sie eskalieren sollten

Kontaktieren Sie einen Admin oder Super Admin, wenn Sie Folgendes benoetigen:

- Ein Haustierprofil loeschen, das vollstaendig entfernt werden soll
- Eine Paarungsanzeige entfernen (Sie koennen moderieren/markieren, aber nicht loeschen)
- Auf Benutzerfeedback antworten, das eine offizielle Antwort erfordert
- Eine Benachrichtigung an betroffene Benutzer ueber eine Moderationsmassnahme senden
- Einen Blogbeitrag ueber Gemeinschaftsrichtlinien erstellen oder bearbeiten
- Auf Analysedaten fuer einen Moderationsbericht zugreifen

---

## Tipps fuer effektive Moderation

- **Seien Sie konsistent** - Wenden Sie die gleichen Standards auf alle Verifizierungspruefungen an. Dokumentieren Sie Ihre Begruendung in der Ablehnungsnachricht.
- **Handeln Sie zeitnah** - Verifizierungsantragsteller warten. Versuchen Sie, Einreichungen innerhalb von 24 Stunden zu bearbeiten.
- **Im Zweifelsfall eskalieren** - Wenn ein Verifizierungsfall unklar ist, markieren Sie ihn und bitten Sie einen Admin um eine zweite Meinung, anstatt eine fragwuerdige Genehmigung zu erteilen.
- **Sperren Sie mit Bedacht** - Sperren ist eine ernste Massnahme. Reservieren Sie es fuer eindeutige Richtlinienverstoesse, nicht fuer geringfuegige Probleme.
