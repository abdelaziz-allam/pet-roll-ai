# Snelstart: Admin

Welkom bij het Petfolioo Admin Portaal. Als Admin heb je brede operationele toegang om gebruikers, huisdieren, content en dagelijkse platformactiviteiten te beheren. Deze gids behandelt wat je kunt doen, je dagelijkse workflow en wanneer je moet escaleren naar een Super Admin.

---

## Beschikbare pagina's

| Pagina | Beschikbare acties |
|--------|-------------------|
| Dashboard | View platform KPIs en analyses |
| App-gebruikers | View, Create, Edit, Ban |
| Huisdieren | View, Edit, Delete |
| Huisdiercategorieen | View, Create, Edit, Delete |
| Verificatie | View, Approve, Reject |
| Dekdienst | View, Edit, Delete, Moderate |
| Gezondheidscertificaten | View, Approve, Reject |

| Meldingen | View, Send |
| Analyses | View, Export |

Pagina's die **niet** in je zijbalk staan: Admin-gebruikers, Instellingen.

---

## Eerste stappen na het verkrijgen van toegang

1. **Log in en controleer je profiel** - Klik op je avatar rechtsboven om te bevestigen dat je naam en e-mail correct zijn.
2. **Verken het Dashboard** - Begrijp de huidige staat van het platform: actieve gebruikers, lopende verificaties, recente activiteit.
3. **Controleer de Verificatiewachtrij** - Bekijk of er fokkers- of huisdierverificaties wachten op actie.
4. **Blader door App-gebruikers** - Sorteer op recente aanmelddatum om nieuwe registraties te zien en vertrouwd te raken met het gebruikersbestand.
5. **Bekijk Feedback** - Controleer op openstaande klachten van gebruikers die een reactie nodig hebben.

---

## Dagelijkse workflow-checklist

- [ ] Open het Dashboard en bekijk KPI-kaarten op ongewone zaken
- [ ] Verwerk lopende items in de Verificatiewachtrij (goedkeuren of afwijzen met reden)
- [ ] Controleer Dekdienst-vermeldingen op nieuwe of gemarkeerde items die moderatie vereisen
- [ ] Bekijk Feedback-inzendingen en reageer op dringende kwesties
- [ ] Monitor App-gebruikers op accounts die gebanned of onderzocht moeten worden
- [ ] Controleer Gezondheidscertificaten op lopende certificaatbeoordelingen
- [ ] Verstuur platformmeldingen als er aankondigingen of onderhoudsvensters zijn
- [ ] Bekijk Analyses op betrokkenheidstrends en exporteer rapporten indien nodig

---

## Belangrijkste verantwoordelijkheden

### Operaties
Jij bent de primaire operator van het platform. Verificatiebeoordelingen, dekdienstmoderatie en gebruikersbeheer zijn je belangrijkste dagelijkse taken. Houd de verificatiewachtrij waar mogelijk onder de 24 uur.

### Contentbeheer
Je beheert de Blog, Huisdiercategorieen en huisdiergegevens. Zorg ervoor dat blogberichten accuraat zijn, categorieen de ondersteunde soorten weerspiegelen en huisdierprofielen correcte informatie bevatten.

### Gebruikersondersteuning
Wanneer app-gebruikers problemen melden via Feedback, ben jij verantwoordelijk voor het reageren. Je kunt gebruikersaccounts bewerken, misbruikende gebruikers bannen en huisdiergegevens namens hen corrigeren.

### Meldingenbeheer
Je kunt platformbrede of gerichte meldingen versturen. Gebruik dit voor onderhoudsvensters, functie-aankondigingen of belangrijke beleidswijzigingen.

---

## Wat je niet kunt doen

| Actie | Wie kan dit |
|-------|-------------|
| App-gebruikers verwijderen | Alleen Super Admin |
| Gebruikersgegevens exporteren | Alleen Super Admin |
| Meldingen verwijderen | Alleen Super Admin |
| Instellingen openen of bewerken | Alleen Super Admin |
| Admin-accounts aanmaken/bewerken/verwijderen | Alleen Super Admin |
| Rolrechten beheren | Alleen Super Admin |

---

## Wanneer escaleren

Neem contact op met je Super Admin wanneer je het volgende nodig hebt:

- Een gebruikersaccount permanent verwijderen (je kunt bannen, maar niet verwijderen)
- Gebruikersgegevens exporteren voor compliance- of juridische verzoeken
- Platforminstellingen of functievlaggen wijzigen
- Admin-toegang verlenen aan een nieuw teamlid
- Een per ongeluk verzonden melding verwijderen
- Een beveiligingsincident afhandelen dat wijzigingen op systeemniveau vereist
