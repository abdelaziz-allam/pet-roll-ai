# Pikaopas: Moderator

Tervetuloa Petfolioo Admin-portaaliin. Moderator-roolissa keskityt sisällön laatuun ja yhteisön turvallisuuteen. Tarkistat verifiointeja, moderoit ilmoituksia ja varmistat, että lemmikkitiedot ovat tarkkoja. Tämä opas kattaa pääsyoikeutesi, päivittäisen työnkulkusi ja rajasi.

---

## Käytettävissäsi olevat sivut

| Sivu | Käytettävissä olevat toiminnot |
|------|-------------------------------|
| Dashboard | View alustan KPI-mittarit |
| Sovelluskäyttäjät | View, Ban |
| Lemmikit | View, Edit |
| Lemmikkikategoriat | View |
| Verifiointi | View, Approve, Reject |
| Paritus | View, Moderate |
| Terveystodistukset | View, Approve, Reject |
| Rokotusanalytiikka | View |
| Palaute | View |
| Blogi | View |
| Ilmoitukset | View |

Sivut, jotka **eivät** näy sivupalkissasi: Analytiikka, Admin-käyttäjät, Asetukset.

---

## Ensimmäiset askeleet pääsyn saamisen jälkeen

1. **Kirjaudu sisään ja tarkista profiilisi** - Napsauta avatariasi vahvistaaksesi, että tietosi ovat oikein.
2. **Avaa verifiointijono** - Tämä on ensisijainen työtilasi. Katso mitä odottaa tarkistusta.
3. **Selaa Paritus-sivua** - Tutustu aktiivisiin ilmoituksiin ja käytettävissä oleviin moderointityökaluihin.
4. **Tutustu Lemmikkeihin** - Napsauta muutamaa lemmikkiprofiilia ymmärtääksesi tietorakenteen ja mitkä kentät voit muokata.
5. **Tarkista Dashboard** - Saa peruskäsitys alustan aktiivisuustasosta.

## Päivittäinen työnkulun tarkistuslista

- [ ] Tarkista Dashboard nopeaa terveysyleiskuvaa varten
- [ ] Käsittele verifiointijono: tarkista dokumentit, hyväksy lailliset kasvattajat, hylkää puutteelliset tai vilpilliset hakemukset selkein perusteluin
- [ ] Moderoi paritusilmoituksia: liputa tai poista sopimatonta sisältöä, varmista ilmoituksen tarkkuus
- [ ] Tarkista Lemmikit raportoitujen tai liputettujen profiilien osalta ja korjaa epätarkat tiedot
- [ ] Tarkista Terveystodistukset odottavien sertifiointitarkistusten osalta
- [ ] Bannaa ongelmalliset käyttäjät, jotka rikkovat yhteisön ohjeita
- [ ] Selaa Palautetta käyttäjäraporttien varalta sisältöongelmista (vaikka et voi vastata, voit toimia lukemasi perusteella)

## Keskeiset vastuualueet

### Verifiointitarkistukset
Tärkein tehtäväsi. Kasvattajat lähettävät dokumentaatiota todistaakseen laillisuutensa ja pätevyytensä. Tarkistat nämä dokumentit aitouden, täydellisyyden ja alustan standardien noudattamisen osalta. Hyväksy lailliset hakemukset nopeasti ja hylkää vilpilliset selkeällä selityksellä.

### Paritusmoderointi
Seuraa paritusmarkkinapaikkaa sopimattoman sisällön, harhaanjohtavien kuvausten tai käytäntörikkomusten varalta. Käytä Moderate-toimintoa ongelmallisten ilmoitusten liputtamiseen tai piilottamiseen.

### Lemmikkitietojen laatu
Voit muokata lemmikkiprofiileja korjataksesi epätarkkoja rotutietoja, korjataksesi kirjoitusvirheitä, päivittääksesi terveystilaa tai poistaaksesi sopimattomia kuvia. Pidä lemmikirekisteri tarkkana ja luotettavana.

### Yhteisöturvallisuus
Voit bannata käyttäjiä, jotka rikkovat alustan ohjeita. Käytä tätä roskapostitileille, väärinkäyttäville käyttäjille tai käyttäjille, jotka toistuvasti lähettävät vilpillisiä verifiointeja.

### Terveystodistustarkistus
Tarkista lähetetyt terveystodistukset tarkkuuden osalta ja hyväksy tai hylkää ne toimitetun dokumentaation perusteella.

## Milloin eskaloida

Ota yhteyttä Adminiin tai Super Adminiin, kun sinun tarvitsee:

- Poistaa lemmikkiprofiili, joka pitäisi poistaa kokonaan
- Poistaa paritusilmoitus (voit moderoida/liputtaa, mutta et poistaa)
- Vastata käyttäjäpalautteeseen, joka vaatii virallisen vastauksen
- Lähettää ilmoitus käyttäjille moderointitoimenpiteestä
- Luoda tai muokata blogikirjoitusta yhteisöohjeista
- Käyttää analytiikkatietoja moderointiraporttia varten

---

## Vinkkejä tehokkaaseen moderointiin

- **Ole johdonmukainen** - Sovella samoja standardeja kaikkiin verifiointitarkistuksiin. Dokumentoi perustelusi hylkäysviestissä.
- **Toimi nopeasti** - Verifiointihakijat odottavat. Yritä käsitellä hakemukset 24 tunnin sisällä.
- **Epävarmoissa tilanteissa eskaloi** - Jos verifiointitapaus on epäselvä, liputa se ja pyydä Adminilta toinen mielipide sen sijaan, että tekisit kyseenalaisen hyväksynnän.
- **Bannaa harkiten** - Bannaus on vakava toimenpide. Varaa se selville käytäntörikkomuksille, ei pienille ongelmille.
