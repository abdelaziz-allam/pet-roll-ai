# Pikaopas: Viewer

Tervetuloa Petfolioo Admin-portaaliin. Viewer-roolissa sinulla on vain luku -pääsy useimpiin alustan sivuihin. Roolisi tarjoaa näkyvyyden alustan toimintoihin ilman mahdollisuutta muokata tietoja. Tämä opas kattaa mitä voit nähdä, miten käytät portaalia tehokkaasti ja miten voit pyytää laajennettuja oikeuksia tarvittaessa.

---

## Käytettävissäsi olevat sivut

| Sivu | Pääsytaso |
|------|-----------|
| Dashboard | View KPI-mittarit ja analytiikkakaaviot |
| Sovelluskäyttäjät | View käyttäjälista ja profiilit |
| Lemmikit | View lemmikirekisteri ja profiilit |
| Lemmikkikategoriat | View kategoriatakataksonomia |
| Verifiointi | View jono ja lähetyksen tila |
| Paritus | View markkinapaikkailmoitukset |
| Terveystodistukset | View sertifiointirekisterit |
| Rokotusanalytiikka | View rokotustiedot |
| Palaute | View käyttäjälähetykset |
| Blogi | View julkaistut kirjoitukset |
| Ilmoitukset | View lähetetyt ilmoitukset |
| Analytiikka | View kaaviot ja mittarit |

Sivut, jotka **eivät** näy sivupalkissasi: Admin-käyttäjät, Asetukset.

---

## Mitä "vain luku" tarkoittaa käytännössä

Käyttöliittymäsi on virtaviivainen verrattuna muihin rooleihin:

| UI-elementti | Mitä näet |
|--------------|-----------|
| Create/Add-painikkeet | Piilotettu - ei näkyvissä missään |
| Edit-painikkeet | Piilotettu - taulukon rivejä ei voi napsauttaa muokkausta varten |
| Delete-vaihtoehdot | Piilotettu - ei toimintovalikkoja tuhoavilla vaihtoehdoilla |
| Approve/Reject-painikkeet | Piilotettu - verifiointitila näytetään vain luku -tekstinä |
| Send Notification -painike | Piilotettu |
| Export-painikkeet | Piilotettu |
| Ban/Unban-painikkeet | Piilotettu |

Näet samat tiedot kuin muut roolit, mutta käyttöliittymä poistaa kaikki toimintopainikkeet. Tämä tarkoittaa, ettet voi vahingossa muokata mitään. Taulukot, kaaviot, yksityiskohtanäkymät ja tilailmaisimet näkyvät normaalisti.

---

## Ensimmäiset askeleet pääsyn saamisen jälkeen

1. **Kirjaudu sisään ja vahvista profiilisi** - Napsauta avatariasi vahvistaaksesi tilisi tiedot.
2. **Tutustu Dashboardiin** - Tämä on kotisivusi. Tutki KPI-kortteja ja analytiikkakaavioita ymmärtääksesi alustan terveyden yhdellä silmäyksellä.
3. **Vieraile Analytiikassa** - Tarkista sitoutumistrendit, kasvumittarit ja alustan käyttömallit.
4. **Selaa Sovelluskäyttäjiä ja Lemmikkejä** - Tutustu saatavilla oleviin tietoihin raportointitarpeitasi varten.
5. **Tarkista Verifiointi** - Ymmärrä jonon tila ja hyväksymisaste arvioidaksesi operatiivista kuormitusta.

## Keskeiset vastuualueet

### Valvonta
Ensisijainen arvosi on tietoinen valvonta. Voit nähdä koko kuvan alustan toiminnasta ilman toimintatarvetta. Käytä tätä trendien tunnistamiseen, mahdollisten ongelmien varhaiseen havaitsemiseen ja sidosryhmien pitämiseen ajan tasalla.

### Raportointi
Vaikka et voi viedä tietoja suoraan portaalista, voit käyttää näkemääsi raporttien laatimiseen ulkoisesti. Dashboard- ja Analytiikka-sivut tarjoavat mittarit, joita useimmin tarvitaan sidosryhmäpäivityksiin.

### Seuranta
Tarkkaile epätavallisia malleja: äkillisiä laskuja verifiointihyväksynnöissä, piikkejä käyttäjäbannauksissa tai laskevia sitoutumismittareita. Kun havaitset jotain huolestuttavaa, nosta se esiin Adminille tai Super Adminille, joka voi tutkia ja toimia.

### Sidosryhmänäkyvyys
Jos olet liiketoiminnan sidosryhmä, sijoittaja tai kumppani, Viewer-rooli antaa sinulle läpinäkyvyyden alustan toimintoihin ilman, että tiimin tarvitsee laatia erillisiä raportteja sinulle.

---

## Raporttien laatiminen katseluoikeuksilla

Koska et voi viedä tietoja suoraan, tässä tehokkaita lähestymistapoja:

1. **Kuvakaappaukset** - Tallenna Dashboard- ja Analytiikkakaaviot esityksiä varten.
2. **Manuaaliset muistiinpanot** - Kirjaa tärkeimmät mittarit KPI-korteista päivittäisen tarkistuksesi aikana.
3. **Pyydä vientejä** - Pyydä Adminia tai Super Adminia viemään tietoja, joita tarvitset syvempää analyysiä varten.
4. **Säännölliset tarkistukset** - Aseta toistuva aika portaalin tarkistamiseen ja muutosten merkitsemiseen viikosta toiseen.

---

## Miten pyytää laajennettuja oikeuksia

Jos vastuualueesi muuttuvat ja tarvitset mahdollisuuden toimia (hyväksyä verifiointeja, moderoida sisältöä, hallita käyttäjiä), noudata tätä prosessia:

1. Tunnista mitkä toiminnot tarvitset ja miksi.
2. Ota yhteyttä organisaatiosi Super Adminiin pyynnölläsi.
3. Määrittele tarvitsetko roolin päivityksen (Moderator tai Admin) vai vain tiettyjä lisäoikeuksia.
4. Super Admin voi mukauttaa oikeuksiasi muuttamatta roolinimiketäsi, jos vain muutamia lisätoimintoja tarvitaan.

---

## Avun saaminen

Portaalissa näkemääsi koskeviin kysymyksiin löydät vastauksia tämän käyttöoppaan moduulikohtaisilta sivuilta. Pääsypyynnöissä tai alustan tietoja koskevissa huolissa ota yhteyttä Adminiisi tai Super Adminiisi.
