# Glossary

A reference of key terms used throughout the Petfolioo Admin Portal.

---

## A

### Admin User
An account with access to the Admin Portal. Admin users are separate from app users and are assigned one of four roles: Super Admin, Admin, Moderator, or Viewer.

### Analytics
The data visualization and reporting features of the Admin Portal. Analytics dashboards display KPIs, trends, and aggregated statistics about platform activity, pet registrations, and user engagement.

### App User
A user of the Petfolioo mobile application. App users register pets, submit verifications, and interact with the marketplace.

---

## B

### Ban
An action that suspends an app user's account, preventing them from logging in or using any platform features. Bans can be temporary or permanent and are typically issued by Moderators or Admins in response to policy violations.

### Blog Post
Content published through the Admin Portal's blog management system. Blog posts can include articles, announcements, and educational content that appears in the Petfolioo mobile app.

### Breeder Verification
The process by which breeders on the platform submit documentation to prove their legitimacy and credentials. Verified breeders receive a badge and gain access to the Mating Marketplace.

---

## C

### Category
A classification applied to pets, blog posts, or marketplace listings. Categories help organize content and enable filtering throughout the platform.

### Cloud Run
The Google Cloud Run service that hosts the Petfolioo Admin Portal backend. Cloud Run provides serverless container execution with automatic scaling.

---

## D

### Dashboard
The main landing page of the Admin Portal, displaying an overview of key metrics, recent activity, and quick-access links to common tasks.

---

## E

### Export
The ability to download data from the Admin Portal in various formats (CSV, PDF). Exports are available for user lists, pet registries, analytics reports, and other data tables.

---

## F

### Feedback
User-submitted comments, ratings, or reports collected through the mobile app. Feedback items appear in the Admin Portal for review and response by the admin team.

---

## H

### Health Certification
A verified document confirming a pet's health status, issued by a licensed veterinarian. Health certifications are uploaded by app users and validated through the Admin Portal.

---

## K

### KPI
Key Performance Indicator. A measurable value displayed on the Dashboard and Analytics pages that tracks platform health, such as daily active users, new registrations, or verification completion rates.

---

## M

### Mating Marketplace
A platform feature that connects verified pet owners and breeders for mating purposes. Listings in the Mating Marketplace require breeder verification and up-to-date health certifications.

### Microchip ID
A unique identifier associated with a pet's implanted microchip. Microchip IDs are recorded in the Pet Registry and used for identity verification and ownership tracking.

### Moderator
An admin role with permissions to manage app users, review flagged content, handle feedback, and issue bans. Moderators cannot modify system settings or manage other admin accounts.

---

## N

### Notification (Push)
A message sent to app users' devices via the push notification system. Admins can send targeted or broadcast notifications for announcements, reminders, or alerts through the Admin Portal.

---

## P

### Permission
A specific action or access right granted to an admin role. Permissions determine which pages, features, and operations are available to each role within the Admin Portal.

### Pet Registry
The central database of all pets registered on the Petfolioo platform. Each entry includes the pet's profile, species, breed, microchip ID, health records, vaccination history, and ownership information.

---

## R

### RBAC
Role-Based Access Control. The security model used by the Admin Portal to restrict access to features and data based on the admin user's assigned role.

### Role
A named set of permissions assigned to an admin user. The four roles are Super Admin, Admin, Moderator, and Viewer, each with progressively fewer permissions.

---

## S

### Settings
The configuration section of the Admin Portal where Super Admins and Admins can manage platform-wide options including notification preferences, category definitions, and system parameters.

### Species
A top-level classification for pets in the registry (e.g., Dog, Cat, Bird, Rabbit). Species determines which breed options, health certification templates, and vaccination schedules are available.

### Super Admin
The highest-privilege admin role with full access to all portal features, including user management, role assignment, system settings, and destructive operations like permanent data deletion.

---

## V

### Vaccination Analytics
A specialized analytics dashboard that tracks vaccination rates, expiration timelines, and compliance statistics across the pet population on the platform.

### Validity Period
The time window during which a health certification or vaccination record is considered current. After the validity period expires, the record is flagged for renewal.

### Viewer
The most restricted admin role, limited to read-only access. Viewers can browse data and view reports but cannot create, edit, or delete any records.
