# Quick Start: Super Admin

Welcome to the Petfolioo Admin Portal. As a Super Admin, you have unrestricted access to every page, action, and configuration option on the platform. This guide covers your first day, daily workflows, and responsibilities.

---

## First Steps After Initial Login

1. **Verify your profile** - Click your avatar in the top-right and confirm your account details are correct.
2. **Configure platform settings** - Navigate to Settings and review platform-wide configuration (branding, feature flags, notification defaults).
3. **Create additional admin accounts** - Go to Admin Users and create accounts for your team members with appropriate roles.
4. **Seed pet categories** - Visit Pet Categories and ensure the species and breed taxonomy is set up for your region.
5. **Review the Dashboard** - Familiarize yourself with KPI cards so you know what "normal" looks like.

## Daily Workflow Checklist

- [ ] Check the Dashboard for platform health and anomalies
- [ ] Review pending verifications in the Verification queue
- [ ] Scan Feedback for urgent user complaints or bug reports
- [ ] Review the Admin Users list for any access requests or suspicious accounts
- [ ] Check Analytics for trends in user growth and engagement
- [ ] Monitor Mating listings for moderation flags
- [ ] Review notifications sent by other admins for appropriateness
- [ ] Audit Settings periodically for unexpected changes

## Key Responsibilities

### System Configuration
You are the only role that can access the Settings page. This includes platform branding, feature toggles, API keys, and notification templates. Review these quarterly or when launching new features.

### User Management
Only you can create, edit, and delete admin accounts. When onboarding new team members, assign the minimum role they need (prefer Moderator or Viewer unless they genuinely need Admin access).

### Security Oversight
- Keep the number of Super Admin accounts to 2-3 maximum.
- Review admin user activity quarterly and suspend unused accounts.
- You are the only role that can delete app users and export user data, so handle GDPR and data requests personally.

### Escalation Point
Other roles will escalate to you when they need actions outside their permissions: deleting users, exporting data, changing settings, or managing admin accounts.

## Tips for Delegating Work

| Task | Delegate To |
|------|-------------|
| Daily verification reviews | Admin or Moderator |
| Mating moderation | Admin or Moderator |
| Pet data corrections | Admin or Moderator |
| Sending platform notifications | Admin |
| Analytics monitoring and reporting | Admin or Viewer |
| Banning problematic users | Admin or Moderator |
| Blog content management | Admin |

Reserve your time for tasks only you can perform: settings changes, admin user management, data exports, and security audits. The more you delegate operational work, the more capacity you have for strategic oversight.
