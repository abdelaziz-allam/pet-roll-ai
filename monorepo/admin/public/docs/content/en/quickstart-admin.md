# Quick Start: Admin

Welcome to the Petfolioo Admin Portal. As an Admin, you have broad operational access to manage users, pets, content, and day-to-day platform activities. This guide covers what you can do, your daily workflow, and when to escalate to a Super Admin.

---

## Pages Available to You

| Page | Actions Available |
|------|-------------------|
| Dashboard | View platform KPIs and analytics |
| App Users | View, Create, Edit, Ban |
| Pets | View, Edit, Delete |
| Pet Categories | View, Create, Edit, Delete |
| Verification | View, Approve, Reject |
| Mating | View, Edit, Delete, Moderate |
| Health Certs | View, Approve, Reject |
| Vax Analytics | View, Export |
| Feedback | View, Respond |
| Blog | View, Create, Edit, Delete |
| Notifications | View, Send |
| Analytics | View, Export |

Pages **not** in your sidebar: Admin Users, Settings.

---

## First Steps After Being Granted Access

1. **Log in and verify your profile** - Click your avatar in the top-right to confirm your name and email are correct.
2. **Explore the Dashboard** - Understand the platform's current state: active users, pending verifications, recent activity.
3. **Check the Verification queue** - See if there are pending breeder or pet verifications awaiting action.
4. **Browse App Users** - Sort by recent join date to see new registrations and familiarize yourself with the user base.
5. **Review Feedback** - Check for any open user complaints that need a response.

---

## Daily Workflow Checklist

- [ ] Open the Dashboard and review KPI cards for anything unusual
- [ ] Process pending items in the Verification queue (approve or reject with reason)
- [ ] Check Mating listings for new or flagged entries requiring moderation
- [ ] Review Feedback submissions and respond to urgent issues
- [ ] Monitor App Users for accounts that need banning or investigation
- [ ] Check Health Certs for pending certification reviews
- [ ] Send platform notifications if there are announcements or maintenance windows
- [ ] Review Analytics for engagement trends and export reports as needed

---

## Key Responsibilities

### Operations
You are the primary operator of the platform. Verification reviews, mating moderation, and user management are your core daily tasks. Keep the verification queue under 24 hours old whenever possible.

### Content Management
You manage the Blog, Pet Categories, and pet data. Ensure blog posts are accurate, categories reflect the supported species, and pet profiles have correct information.

### User Support
When app users report issues through Feedback, you are responsible for responding. You can edit user accounts, ban abusive users, and correct pet data on their behalf.

### Notification Management
You can send platform-wide or targeted notifications. Use this for maintenance windows, feature announcements, or important policy changes.

## What You Cannot Do

| Action | Who Can |
|--------|---------|
| Delete app users | Super Admin only |
| Export user data | Super Admin only |
| Delete notifications | Super Admin only |
| Access or edit Settings | Super Admin only |
| Create/edit/delete admin accounts | Super Admin only |
| Manage role permissions | Super Admin only |

---

## When to Escalate

Contact your Super Admin when you need to:

- Remove a user account permanently (you can ban, but not delete)
- Export user data for compliance or legal requests
- Change platform settings or feature flags
- Grant admin access to a new team member
- Delete a notification that was sent in error
- Handle a security incident that requires system-level changes
