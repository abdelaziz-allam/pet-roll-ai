# Hurtigstart: Viewer

Velkommen til Petfolioo Admin-portalen. Som Viewer har du skrivebeskyttet tilgang til de fleste plattformsider. Rollen din gir synlighet i plattformdriften uten mulighet til å endre data. Denne guiden dekker hva du kan se, hvordan du bruker portalen effektivt, og hvordan du ber om utvidet tilgang ved behov.

---

## Sider tilgjengelige for deg

| Side | Tilgangsnivå |
|------|--------------|
| Dashboard | View KPIer og analysediagrammer |
| App-brukere | View brukerliste og profiler |
| Kjæledyr | View kjæledyrregister og profiler |
| Kjæledyrskategorier | View kategoritaksonomi |
| Verifisering | View kø og innsendingsstatus |
| Paring | View markedsplassoppføringer |
| Helsesertifikater | View sertifiseringsregistre |
| Vaksinasjonsanalyser | View vaksinasjonsdata |
| Feedback | View brukerinnsendinger |
| Blogg | View publiserte innlegg |
| Varsler | View sendte varsler |
| Analyser | View diagrammer og metrikker |

Sider som **ikke** er i sidemenyen din: Admin-brukere, Innstillinger.

---

## Hva "kun visning" betyr i praksis

Grensesnittet ditt er strømlinjeformet sammenlignet med andre roller:

| UI-element | Hva du ser |
|------------|------------|
| Create/Add-knapper | Skjulte - ikke synlige noe sted |
| Edit-knapper | Skjulte - tabellrader er ikke klikkbare for redigering |
| Delete-alternativer | Skjulte - ingen handlingsmenyer med destruktive alternativer |
| Approve/Reject-knapper | Skjulte - verifiseringsstatus vist som skrivebeskyttet tekst |
| Send Notification-knapp | Skjult |
| Export-knapper | Skjulte |
| Ban/Unban-knapper | Skjulte |

Du ser de samme dataene som andre roller, men grensesnittet fjerner alle handlingskontroller. Dette betyr at du ikke ved et uhell kan endre noe. Tabeller, diagrammer, detaljvisninger og statusindikatorer vises normalt.

## Første steg etter tildeling av tilgang

1. **Logg inn og bekreft profilen din** - Klikk på avataren din for å bekrefte kontodetaljene dine.
2. **Utforsk Dashboard** - Dette er hjemmebasen din. Studer KPI-kortene og analysediagrammene for å forstå plattformhelsen med et blikk.
3. **Besøk Analyser** - Gjennomgå engasjementstrender, vekstmetrikker og plattformbruksmønstre.
4. **Bla gjennom App-brukere og Kjæledyr** - Gjør deg kjent med tilgjengelige data for dine rapporteringsbehov.
5. **Sjekk Verifisering** - Forstå køstatus og godkjenningsrate for å vurdere den operasjonelle belastningen.

## Viktigste ansvarsområder

### Tilsyn
Din primære verdi er informert tilsyn. Du kan se det fulle bildet av plattformdriften uten å måtte handle. Bruk dette til å identifisere trender, oppdage potensielle problemer tidlig og holde interessenter informert.

### Rapportering
Selv om du ikke kan eksportere data direkte fra portalen, kan du bruke det du ser til å utarbeide rapporter eksternt. Dashboard- og Analysesidene leverer metrikkene som oftest trengs for interessentoppdateringer.

### Overvåking
Hold øye med uvanlige mønstre: plutselige fall i verifiseringsgodkjenninger, økninger i brukerutestenginger, eller synkende engasjementsmetrikker. Når du oppdager noe bekymringsfullt, ta det opp med en Admin eller Super Admin som kan undersøke og handle.

### Interessentsynlighet
Hvis du er en forretningsinteressent, investor eller partner, gir Viewer-rollen deg transparens i plattformdriften uten at teamet trenger å utarbeide separate rapporter for deg.

---

## Utarbeidelse av rapporter med visningstilgang

Siden du ikke kan eksportere data direkte, er her effektive tilnærminger:

1. **Skjermbilder** - Ta Dashboard- og Analysediagrammer for presentasjoner.
2. **Manuelle notater** - Registrer viktige metrikker fra KPI-kort under din daglige gjennomgang.
3. **Be om eksporter** - Spør en Admin eller Super Admin om å eksportere data du trenger for dypere analyse.
4. **Planlagte gjennomganger** - Sett en jevnlig tid for å gjennomgå portalen og notere endringer uke for uke.

---

## Slik ber du om utvidet tilgang

Hvis ansvarsområdene dine endres og du trenger muligheten til å handle (godkjenne verifiseringer, moderere innhold, administrere brukere), følg denne prosessen:

1. Identifiser hvilke spesifikke handlinger du trenger og hvorfor.
2. Kontakt organisasjonens Super Admin med forespørselen din.
3. Spesifiser om du trenger en rolleoppgradering (til Moderator eller Admin) eller bare spesifikke ekstra tillatelser.
4. Super Admin kan tilpasse tillatelsene dine uten å endre rollenavnet ditt hvis bare noen få ekstra handlinger trengs.
