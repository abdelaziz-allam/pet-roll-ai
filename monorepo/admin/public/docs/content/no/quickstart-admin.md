# Hurtigstart: Admin

Velkommen til Petfolioo Admin-portalen. Som Admin har du bred operasjonell tilgang til å administrere brukere, kjæledyr, innhold og daglige plattformaktiviteter. Denne guiden dekker hva du kan gjøre, din daglige arbeidsflyt, og når du bør eskalere til en Super Admin.

---

## Sider tilgjengelige for deg

| Side | Tilgjengelige handlinger |
|------|--------------------------|
| Dashboard | View plattform-KPIer og analyser |
| App-brukere | View, Create, Edit, Ban |
| Kjæledyr | View, Edit, Delete |
| Kjæledyrskategorier | View, Create, Edit, Delete |
| Verifisering | View, Approve, Reject |
| Paring | View, Edit, Delete, Moderate |
| Helsesertifikater | View, Approve, Reject |
| Vaksinasjonsanalyser | View, Export |
| Feedback | View, Respond |
| Blogg | View, Create, Edit, Delete |
| Varsler | View, Send |
| Analyser | View, Export |

Sider som **ikke** er i sidemenyen din: Admin-brukere, Innstillinger.

---

## Første steg etter tildeling av tilgang

1. **Logg inn og bekreft profilen din** - Klikk på avataren din øverst til høyre for å bekrefte at navnet og e-postadressen din er korrekt.
2. **Utforsk Dashboard** - Forstå plattformens nåværende tilstand: aktive brukere, ventende verifiseringer, nylig aktivitet.
3. **Sjekk verifiseringskøen** - Se om det er ventende oppdretter- eller kjæledyrverifiseringer som venter på handling.
4. **Bla gjennom App-brukere** - Sorter etter nyeste registreringsdato for å se nye registreringer og gjøre deg kjent med brukergruppen.
5. **Gjennomgå Feedback** - Sjekk for åpne brukerklager som trenger et svar.

---

## Daglig arbeidsflyt-sjekkliste

- [ ] Åpne Dashboard og gjennomgå KPI-kort for noe uvanlig
- [ ] Behandle ventende elementer i verifiseringskøen (godkjenn eller avvis med begrunnelse)
- [ ] Sjekk paringsannonser for nye eller flaggede oppføringer som krever moderering
- [ ] Gjennomgå Feedback-innsendinger og svar på akutte problemer
- [ ] Overvåk App-brukere for kontoer som trenger banning eller undersøkelse
- [ ] Sjekk Helsesertifikater for ventende sertifiseringsgjennomganger
- [ ] Send plattformvarsler hvis det er kunngjøringer eller vedlikeholdsvinduer
- [ ] Gjennomgå Analyser for engasjementstrender og eksporter rapporter etter behov

---

## Viktigste ansvarsområder

### Drift
Du er den primære operatøren av plattformen. Verifiseringsgjennomganger, paringsmoderering og brukeradministrasjon er dine daglige kjerneoppgaver. Hold verifiseringskøen under 24 timer gammel når mulig.

### Innholdsstyring
Du administrerer Blogg, Kjæledyrskategorier og kjæledyrdata. Sørg for at blogginnlegg er nøyaktige, kategorier reflekterer de støttede artene, og kjæledyrprofiler har korrekt informasjon.

### Brukerstøtte
Når app-brukere rapporterer problemer via Feedback, er du ansvarlig for å svare. Du kan redigere brukerkontoer, banne misbrukende brukere og korrigere kjæledyrdata på deres vegne.

### Varslingsstyring
Du kan sende plattformomfattende eller målrettede varsler. Bruk dette for vedlikeholdsvinduer, funksjonskunngjøringer eller viktige policyendringer.

---

## Hva du ikke kan gjøre

| Handling | Hvem kan |
|----------|----------|
| Delete app-brukere | Kun Super Admin |
| Export brukerdata | Kun Super Admin |
| Delete varsler | Kun Super Admin |
| Åpne eller redigere Innstillinger | Kun Super Admin |
| Create/Edit/Delete admin-kontoer | Kun Super Admin |
| Manage Permissions for roller | Kun Super Admin |

---

## Når du bør eskalere

Kontakt din Super Admin når du trenger å:

- Fjerne en brukerkonto permanent (du kan banne, men ikke slette)
- Eksportere brukerdata for compliance- eller juridiske forespørsler
- Endre plattforminnstillinger eller feature flags
- Gi admin-tilgang til et nytt teammedlem
- Slette et varsel som ble sendt ved en feil
- Håndtere en sikkerhetshendelse som krever endringer på systemnivå

---

## Få hjelp

For modulspesifikk veiledning, konsulter de andre sidene i denne brukermanualen. For tilgangs- eller tillatelsessproblemer, kontakt organisasjonens Super Admin.
