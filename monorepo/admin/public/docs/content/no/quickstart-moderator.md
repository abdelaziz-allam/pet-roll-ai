# Hurtigstart: Moderator

Velkommen til Petfolioo Admin-portalen. Som Moderator er fokuset ditt innholdskvalitet og fellesskapssikkerhet. Du gjennomgår verifiseringer, modererer oppføringer og sørger for at kjæledyrdata er nøyaktige. Denne guiden dekker tilgangen din, daglige arbeidsflyt og grenser.

---

## Sider tilgjengelige for deg

| Side | Tilgjengelige handlinger |
|------|--------------------------|
| Dashboard | View plattform-KPIer |
| App-brukere | View, Ban |
| Kjæledyr | View, Edit |
| Kjæledyrskategorier | View |
| Verifisering | View, Approve, Reject |
| Paring | View, Moderate |
| Helsesertifikater | View, Approve, Reject |
| Vaksinasjonsanalyser | View |
| Feedback | View |
| Blogg | View |
| Varsler | View |

Sider som **ikke** er i sidemenyen din: Analyser, Admin-brukere, Innstillinger.

---

## Første steg etter tildeling av tilgang

1. **Logg inn og sjekk profilen din** - Klikk på avataren din for å bekrefte at detaljene dine er korrekte.
2. **Åpne verifiseringskøen** - Dette er ditt primære arbeidsområde. Se hva som venter på gjennomgang.
3. **Bla gjennom Paring-siden** - Gjør deg kjent med aktive oppføringer og de tilgjengelige modereringsverktøyene.
4. **Utforsk Kjæledyr** - Klikk inn på noen kjæledyrprofiler for å forstå datastrukturen og hvilke felt du kan redigere.
5. **Gjennomgå Dashboard** - Få en grunnleggende forståelse av plattformens aktivitetsnivå.

---

## Daglig arbeidsflyt-sjekkliste

- [ ] Sjekk Dashboard for en rask helseoversikt
- [ ] Behandle verifiseringskøen: gjennomgå dokumenter, godkjenn legitime oppdrettere, avvis ufullstendige eller svindelaktige innsendinger med klare begrunnelser
- [ ] Moderer paringsannonser: flagg eller fjern upassende innhold, bekreft oppføringens nøyaktighet
- [ ] Gjennomgå Kjæledyr for rapporterte eller flaggede profiler og korriger unøyaktige data
- [ ] Sjekk Helsesertifikater for ventende sertifiseringsgjennomganger
- [ ] Bann problematiske brukere som bryter fellesskapsretningslinjene
- [ ] Skann Feedback for brukerrapporter om innholdsproblemer (selv om du ikke kan svare, kan du handle på det du leser)

## Viktigste ansvarsområder

### Verifiseringsgjennomganger
Din viktigste oppgave. Oppdrettere sender inn dokumentasjon for å bevise sin legitimitet og sine kvalifikasjoner. Du gjennomgår disse dokumentene for ekthet, fullstendighet og overholdelse av plattformens standarder. Godkjenn legitime søknader raskt og avvis svindelaktige med en klar forklaring.

### Paringsmoderering
Overvåk paringsmarkedsplassen for upassende innhold, villedende beskrivelser eller policybrudd. Bruk Moderate-handlingen for å flagge eller skjule problematiske oppføringer.

### Kjæledyrdatakvalitet
Du kan redigere kjæledyrprofiler for å korrigere unøyaktig raseinformasjon, rette skrivefeil, oppdatere helsestatus eller fjerne upassende bilder. Hold kjæledyrregisteret nøyaktig og pålitelig.

### Fellesskapssikkerhet
Du kan banne brukere som bryter plattformens retningslinjer. Bruk dette for spamkontoer, misbrukende atferd eller brukere som gjentatte ganger sender inn svindelaktige verifiseringer.

### Helsesertifiseringsgjennomgang
Gjennomgå innsendte helsesertifiseringer for nøyaktighet og godkjenn eller avvis dem basert på den fremlagte dokumentasjonen.

## Når du bør eskalere

Kontakt en Admin eller Super Admin når du trenger å:

- Slette en kjæledyrprofil som bør fjernes helt
- Fjerne en paringsoppføring (du kan moderere/flagge, men ikke slette)
- Svare på brukerfeedback som krever et offisielt svar
- Sende et varsel til berørte brukere om en modereringshandling
- Opprette eller redigere et blogginnlegg om fellesskapsretningslinjer
- Få tilgang til analysedata for en modereringsrapport

---

## Tips for effektiv moderering

- **Vær konsekvent** - Bruk de samme standardene på alle verifiseringsgjennomganger. Dokumenter begrunnelsen din i avvisningsbeskjeden.
- **Handle raskt** - Verifiseringssøkere venter. Forsøk å behandle innsendinger innen 24 timer.
- **Når du er i tvil, eskaler** - Hvis en verifiseringssak er tvetydig, flagg den og be en Admin om en second opinion i stedet for å gjøre en tvilsom godkjenning.
- **Bann med omtanke** - Banning er en alvorlig handling. Reserver den for klare policybrudd, ikke mindre problemer.
