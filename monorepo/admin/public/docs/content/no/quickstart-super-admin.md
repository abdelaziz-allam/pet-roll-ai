# Hurtigstart: Super Admin

Velkommen til Petfolioo Admin-portalen. Som Super Admin har du ubegrenset tilgang til alle sider, handlinger og konfigurasjonsalternativer på plattformen. Denne guiden dekker din første dag, daglige arbeidsflyter og ansvarsområder.

---

## Sider tilgjengelige for deg

| Side | Tilgjengelige handlinger |
|------|--------------------------|
| Dashboard | View plattform-KPIer og analyser |
| App-brukere | View, Create, Edit, Ban, Delete, Export |
| Kjæledyr | View, Edit, Delete |
| Kjæledyrskategorier | View, Create, Edit, Delete |
| Verifisering | View, Approve, Reject |
| Paring | View, Edit, Delete, Moderate |
| Helsesertifikater | View, Approve, Reject |
| Vaksinasjonsanalyser | View, Export |
| Feedback | View, Respond, Delete |
| Blogg | View, Create, Edit, Delete |
| Varsler | View, Send, Delete |
| Analyser | View, Export |
| Admin-brukere | View, Create, Edit, Delete, Manage Permissions |
| Innstillinger | View, Edit |

Du har tilgang til alt. Ingen sider er skjult fra sidemenyen din.

---

## Første steg etter innledende innlogging

1. **Bekreft profilen din** - Klikk på avataren din øverst til høyre og bekreft at kontodetaljene dine er korrekte.
2. **Konfigurer plattforminnstillinger** - Naviger til Innstillinger og gjennomgå den plattformomfattende konfigurasjonen (merkevarebygging, feature flags, standard varsler).
3. **Opprett flere admin-kontoer** - Gå til Admin-brukere og opprett kontoer for teammedlemmene dine med passende roller.
4. **Sett opp kjæledyrskategorier** - Besøk Kjæledyrskategorier og sørg for at arts- og rasetaksonomien er satt opp for din region.
5. **Gjennomgå Dashboard** - Gjør deg kjent med KPI-kortene slik at du vet hva "normalt" ser ut som.

## Viktigste ansvarsområder

### Systemkonfigurasjon
Du er den eneste rollen som kan åpne Innstillinger-siden. Dette inkluderer plattform-merkevarebygging, feature toggles, API-nøkler og varslingsmaler. Gjennomgå disse kvartalsvis eller ved lansering av nye funksjoner.

### Brukeradministrasjon
Kun du kan opprette, redigere og slette admin-kontoer. Når du onboarder nye teammedlemmer, tildel den minimale rollen de trenger (foretrekk Moderator eller Viewer med mindre de genuint trenger Admin-tilgang).

### Sikkerhetsoversikt
- Hold antallet Super Admin-kontoer på maksimalt 2-3.
- Gjennomgå admin-brukeraktivitet kvartalsvis og suspender ubrukte kontoer.
- Du er den eneste rollen som kan slette app-brukere og eksportere brukerdata, så håndter GDPR- og dataforespørsler personlig.

### Eskaleringspunkt
Andre roller vil eskalere til deg når de trenger handlinger utenfor sine tillatelser: sletting av brukere, eksport av data, endring av innstillinger eller administrasjon av admin-kontoer.

## Tips for delegering av arbeid

| Oppgave | Deleger til |
|---------|-------------|
| Daglige verifiseringsgjennomganger | Admin eller Moderator |
| Paringsmoderering | Admin eller Moderator |
| Kjæledyrdatakorreksjoner | Admin eller Moderator |
| Sending av plattformvarsler | Admin |
| Analyseovervåking og rapportering | Admin eller Viewer |
| Banning av problematiske brukere | Admin eller Moderator |
| Blogginnholdsstyring | Admin |

Reserver tiden din for oppgaver bare du kan utføre: innstillingsendringer, admin-brukeradministrasjon, dataeksporter og sikkerhetsrevisjoner. Jo mer du delegerer operasjonelt arbeid, desto mer kapasitet har du for strategisk oversikt.

## Få hjelp
