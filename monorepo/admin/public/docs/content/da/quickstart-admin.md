# Hurtig start: Admin

Velkommen til Petfolioo Admin-portalen. Som Admin har du bred operationel adgang til at administrere brugere, kæledyr, indhold og daglige platformaktiviteter. Denne guide dækker, hvad du kan gøre, din daglige arbejdsgang, og hvornår du skal eskalere til en Super Admin.

---

## Sider tilgængelige for dig

| Side | Tilgængelige handlinger |
|------|------------------------|
| Dashboard | View platform-KPIs og analyser |
| App-brugere | View, Create, Edit, Ban |
| Kæledyr | View, Edit, Delete |
| Kæledyrskategorier | View, Create, Edit, Delete |
| Verifikation | View, Approve, Reject |
| Parring | View, Edit, Delete, Moderate |
| Sundhedscertifikater | View, Approve, Reject |
| Vaccinationsanalyser | View, Export |
| Feedback | View, Respond |
| Blog | View, Create, Edit, Delete |
| Notifikationer | View, Send |
| Analyser | View, Export |

Sider der **ikke** er i din sidebar: Admin-brugere, Indstillinger.

---

## Første skridt efter tildeling af adgang

1. **Log ind og bekræft din profil** - Klik på dit avatar i øverste højre hjørne for at bekræfte, at dit navn og din e-mail er korrekte.
2. **Udforsk Dashboard** - Forstå platformens aktuelle tilstand: aktive brugere, ventende verifikationer, seneste aktivitet.
3. **Tjek verifikationskøen** - Se om der er ventende opdrætter- eller kæledyrsverifikationer, der afventer handling.
4. **Gennemse App-brugere** - Sorter efter seneste tilmeldingsdato for at se nye registreringer og gøre dig bekendt med brugergruppen.
5. **Gennemgå Feedback** - Tjek for åbne brugerklager, der har brug for et svar.

---

## Daglig arbejdsgangs-tjekliste

- [ ] Åbn Dashboard og gennemgå KPI-kort for noget usædvanligt
- [ ] Behandl ventende emner i verifikationskøen (godkend eller afvis med begrundelse)
- [ ] Tjek parringslister for nye eller flaggede opslag, der kræver moderation
- [ ] Gennemgå Feedback-indsendelser og svar på akutte problemer
- [ ] Overvåg App-brugere for konti, der kræver banning eller undersøgelse
- [ ] Tjek Sundhedscertifikater for ventende certificeringsgennemgange
- [ ] Send platformnotifikationer, hvis der er meddelelser eller vedligeholdelsevinduer
- [ ] Gennemgå Analyser for engagementstendenser og eksporter rapporter efter behov

---

## Vigtigste ansvarsområder

### Drift
Du er den primære operatør af platformen. Verifikationsgennemgange, parringsmoderation og brugeradministration er dine daglige kerneopgaver. Hold verifikationskøen under 24 timer gammel, når det er muligt.

### Indholdsstyring
Du administrerer Blog, Kæledyrskategorier og kæledyrsdata. Sørg for, at blogindlæg er nøjagtige, kategorier afspejler de understøttede arter, og kæledyrsprofiler har korrekte oplysninger.

### Brugersupport
Når app-brugere rapporterer problemer via Feedback, er du ansvarlig for at svare. Du kan redigere brugerkonti, banne misbrugende brugere og rette kæledyrsdata på deres vegne.

### Notifikationsstyring
Du kan sende platformdækkende eller målrettede notifikationer. Brug dette til vedligeholdelsesvinduer, funktionsmeddelelser eller vigtige politikændringer.

## Hvad du ikke kan gøre

| Handling | Hvem kan |
|----------|----------|
| Delete app-brugere | Kun Super Admin |
| Export brugerdata | Kun Super Admin |
| Delete notifikationer | Kun Super Admin |
| Tilgå eller redigere Indstillinger | Kun Super Admin |
| Create/Edit/Delete admin-konti | Kun Super Admin |
| Manage Permissions for roller | Kun Super Admin |

---

## Hvornår du skal eskalere

Kontakt din Super Admin, når du har brug for at:

- Fjerne en brugerkonto permanent (du kan banne, men ikke slette)
- Eksportere brugerdata til compliance- eller juridiske anmodninger
- Ændre platformindstillinger eller feature flags
- Give admin-adgang til et nyt teammedlem
- Slette en notifikation, der blev sendt ved en fejl
- Håndtere en sikkerhedshændelse, der kræver ændringer på systemniveau
