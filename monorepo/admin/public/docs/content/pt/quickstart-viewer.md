# Inicio Rapido: Viewer

Bem-vindo ao Portal de Administracao do Petfolioo. Como Viewer, voce tem acesso somente leitura a maioria das paginas da plataforma. Sua funcao oferece visibilidade das operacoes da plataforma sem a capacidade de modificar quaisquer dados. Este guia abrange o que voce pode ver, como usar o portal de forma eficaz e como solicitar acesso elevado, se necessario.

---

## Paginas disponiveis para voce

| Pagina | Nivel de acesso |
|--------|-----------------|
| Dashboard | View KPIs e graficos de analise |
| Usuarios do aplicativo | View lista de usuarios e perfis |
| Animais | View registro e perfis de animais |
| Categorias de animais | View taxonomia de categorias |
| Verificacao | View fila e status de envios |
| Acasalamento | View anuncios do mercado |
| Certificados de saude | View registros de certificacao |
| Analises de vacinacao | View dados de vacinacao |
| Feedback | View envios de usuarios |
| Blog | View postagens publicadas |
| Notificacoes | View notificacoes enviadas |
| Analises | View graficos e metricas |

Paginas que **nao** estao na sua barra lateral: Usuarios admin, Configuracoes.

---

## O que "Somente visualizacao" significa na pratica

Sua interface e simplificada em comparacao com outras funcoes:

| Elemento da UI | O que voce ve |
|----------------|---------------|
| Botoes Criar/Adicionar | Ocultos - nao visiveis em nenhum lugar |
| Botoes Editar | Ocultos - linhas da tabela nao sao clicaveis para edicao |
| Opcoes de exclusao | Ocultas - sem menus de acao com opcoes destrutivas |
| Botoes Approve/Reject | Ocultos - status de verificacao exibido como texto somente leitura |
| Botao Send Notification | Oculto |
| Botoes Export | Ocultos |
| Botoes Ban/Unban | Ocultos |

Voce ve os mesmos dados que outras funcoes, mas a interface remove todos os controles de acao. Isso significa que voce nao pode modificar nada acidentalmente. Tabelas, graficos, visualizacoes detalhadas e indicadores de status sao exibidos normalmente.

## Primeiros passos apos receber acesso

1. **Faca login e verifique seu perfil** - Clique no seu avatar para confirmar os dados da sua conta.
2. **Explore o Dashboard** - Esta e sua base. Estude os cartoes de KPI e graficos de analise para entender a saude da plataforma rapidamente.
3. **Visite Analises** - Revise tendencias de engajamento, metricas de crescimento e padroes de uso da plataforma.
4. **Navegue por Usuarios do aplicativo e Animais** - Familiarize-se com os dados disponiveis para suas necessidades de relatorio.
5. **Verifique a Verificacao** - Entenda o status da fila e a taxa de aprovacao para avaliar a carga operacional.

## Principais responsabilidades

### Supervisao
Seu valor principal e a supervisao informada. Voce pode ver o quadro completo das operacoes da plataforma sem precisar agir. Use isso para identificar tendencias, detectar problemas potenciais cedo e manter as partes interessadas informadas.

### Relatorios
Embora voce nao possa exportar dados diretamente do portal, pode usar o que ve para preparar relatorios externamente. As paginas Dashboard e Analises fornecem as metricas mais comumente necessarias para atualizacoes de partes interessadas.

### Monitoramento
Observe padroes incomuns: quedas repentinas em aprovacoes de verificacao, picos em banimentos de usuarios ou metricas de engajamento em declinio. Quando identificar algo preocupante, leve ao conhecimento de um Admin ou Super Admin que possa investigar e agir.

### Visibilidade para partes interessadas
Se voce e uma parte interessada empresarial, investidor ou parceiro, a funcao Viewer oferece transparencia nas operacoes da plataforma sem exigir que a equipe prepare relatorios separados para voce.

## Preparando relatorios com acesso somente visualizacao

Como voce nao pode exportar dados diretamente, aqui estao abordagens eficazes:

1. **Capturas de tela** - Capture graficos do Dashboard e Analises para apresentacoes.
2. **Notas manuais** - Registre metricas-chave dos cartoes de KPI durante sua revisao diaria.
3. **Solicite exportacoes** - Peca a um Admin ou Super Admin para exportar dados que voce precisa para analise mais aprofundada.
4. **Revisoes agendadas** - Defina um horario recorrente para revisar o portal e anotar mudancas semana a semana.

---

## Como solicitar acesso elevado

Se suas responsabilidades mudarem e voce precisar da capacidade de realizar acoes (aprovar verificacoes, moderar conteudo, gerenciar usuarios), siga este processo:

1. Identifique quais acoes especificas voce precisa e por que.
2. Entre em contato com o Super Admin da sua organizacao com sua solicitacao.
3. Especifique se voce precisa de uma atualizacao de funcao (para Moderator ou Admin) ou apenas permissoes adicionais especificas.
4. O Super Admin pode personalizar suas permissoes sem alterar o rotulo da sua funcao se apenas algumas acoes extras forem necessarias.
