# Inicio Rapido: Super Admin

Bem-vindo ao Portal de Administracao do Petfolioo. Como Super Admin, voce tem acesso irrestrito a todas as paginas, acoes e opcoes de configuracao da plataforma. Este guia abrange seu primeiro dia, fluxos de trabalho diarios e responsabilidades.

Voce tem acesso a tudo. Nenhuma pagina esta oculta na sua barra lateral.

---

## Primeiros passos apos o login inicial

1. **Verifique seu perfil** - Clique no seu avatar no canto superior direito e confirme que os dados da sua conta estao corretos.
2. **Configure as definicoes da plataforma** - Navegue ate Configuracoes e revise a configuracao geral da plataforma (identidade visual, flags de funcionalidades, padroes de notificacao).
3. **Crie contas admin adicionais** - Va ate Usuarios admin e crie contas para os membros da sua equipe com as funcoes apropriadas.
4. **Configure categorias de animais** - Visite Categorias de animais e garanta que a taxonomia de especies e racas esteja configurada para sua regiao.
5. **Revise o Dashboard** - Familiarize-se com os cartoes de KPI para saber como e o "normal".

## Principais responsabilidades

### Configuracao do sistema
Voce e a unica funcao que pode acessar a pagina de Configuracoes. Isso inclui identidade visual da plataforma, toggles de funcionalidades, chaves de API e modelos de notificacao. Revise-os trimestralmente ou ao lancar novas funcionalidades.

### Gestao de usuarios
Somente voce pode criar, editar e excluir contas admin. Ao integrar novos membros da equipe, atribua a funcao minima necessaria (prefira Moderator ou Viewer a menos que realmente precisem de acesso Admin).

### Supervisao de seguranca
- Mantenha o numero de contas Super Admin em no maximo 2-3.
- Revise a atividade dos usuarios admin trimestralmente e suspenda contas nao utilizadas.
- Voce e a unica funcao que pode excluir usuarios do aplicativo e exportar dados de usuarios, portanto, lide pessoalmente com solicitacoes GDPR e de dados.

### Ponto de escalacao
Outras funcoes escalarao para voce quando precisarem de acoes fora de suas permissoes: excluir usuarios, exportar dados, alterar configuracoes ou gerenciar contas admin.

## Dicas para delegacao de trabalho

| Tarefa | Delegar para |
|--------|--------------|
| Revisoes diarias de verificacao | Admin ou Moderator |
| Moderacao de acasalamento | Admin ou Moderator |
| Correcoes de dados de animais | Admin ou Moderator |
| Envio de notificacoes da plataforma | Admin |
| Monitoramento e relatorios de analises | Admin ou Viewer |
| Banimento de usuarios problematicos | Admin ou Moderator |
| Gestao de conteudo do blog | Admin |

Reserve seu tempo para tarefas que so voce pode realizar: alteracoes de configuracoes, gestao de usuarios admin, exportacoes de dados e auditorias de seguranca. Quanto mais trabalho operacional voce delegar, mais capacidade tera para supervisao estrategica.
