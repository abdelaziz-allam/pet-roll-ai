# Inicio Rapido: Admin

Bem-vindo ao Portal de Administracao do Petfolioo. Como Admin, voce tem amplo acesso operacional para gerenciar usuarios, animais, conteudo e atividades diarias da plataforma. Este guia abrange o que voce pode fazer, seu fluxo de trabalho diario e quando escalar para um Super Admin.

---

## Paginas disponiveis para voce

| Pagina | Acoes disponiveis |
|--------|-------------------|
| Dashboard | View KPIs da plataforma e analises |
| Usuarios do aplicativo | View, Create, Edit, Ban |
| Animais | View, Edit, Delete |
| Categorias de animais | View, Create, Edit, Delete |
| Verificacao | View, Approve, Reject |
| Acasalamento | View, Edit, Delete, Moderate |
| Certificados de saude | View, Approve, Reject |
| Analises de vacinacao | View, Export |
| Feedback | View, Respond |
| Blog | View, Create, Edit, Delete |
| Notificacoes | View, Send |
| Analises | View, Export |

Paginas que **nao** estao na sua barra lateral: Usuarios admin, Configuracoes.

---

## Primeiros passos apos receber acesso

1. **Faca login e verifique seu perfil** - Clique no seu avatar no canto superior direito para confirmar que seu nome e e-mail estao corretos.
2. **Explore o Dashboard** - Entenda o estado atual da plataforma: usuarios ativos, verificacoes pendentes, atividade recente.
3. **Verifique a fila de Verificacao** - Veja se ha verificacoes de criadores ou animais aguardando acao.
4. **Navegue por Usuarios do aplicativo** - Ordene por data de entrada recente para ver novos registros e familiarizar-se com a base de usuarios.
5. **Revise o Feedback** - Verifique se ha reclamacoes abertas de usuarios que precisam de resposta.

## Lista de verificacao do fluxo de trabalho diario

- [ ] Abra o Dashboard e revise os cartoes de KPI em busca de algo incomum
- [ ] Processe itens pendentes na fila de Verificacao (aprove ou rejeite com motivo)
- [ ] Verifique anuncios de Acasalamento em busca de entradas novas ou sinalizadas que requerem moderacao
- [ ] Revise envios de Feedback e responda a questoes urgentes
- [ ] Monitore Usuarios do aplicativo em busca de contas que precisam ser banidas ou investigadas
- [ ] Verifique Certificados de saude em busca de revisoes de certificacao pendentes
- [ ] Envie notificacoes da plataforma se houver anuncios ou janelas de manutencao
- [ ] Revise Analises em busca de tendencias de engajamento e exporte relatorios conforme necessario

## Principais responsabilidades

### Operacoes
Voce e o operador principal da plataforma. Revisoes de verificacao, moderacao de acasalamento e gestao de usuarios sao suas principais tarefas diarias. Mantenha a fila de verificacao com menos de 24 horas sempre que possivel.

### Gestao de conteudo
Voce gerencia o Blog, Categorias de animais e dados de animais. Garanta que as postagens do blog sejam precisas, as categorias reflitam as especies suportadas e os perfis de animais contenham informacoes corretas.

### Suporte ao usuario
Quando usuarios do aplicativo relatam problemas atraves do Feedback, voce e responsavel por responder. Voce pode editar contas de usuarios, banir usuarios abusivos e corrigir dados de animais em nome deles.

### Gestao de notificacoes
Voce pode enviar notificacoes para toda a plataforma ou direcionadas. Use isso para janelas de manutencao, anuncios de funcionalidades ou mudancas importantes de politica.

## O que voce nao pode fazer

| Acao | Quem pode |
|------|-----------|
| Excluir usuarios do aplicativo | Apenas Super Admin |
| Exportar dados de usuarios | Apenas Super Admin |
| Excluir notificacoes | Apenas Super Admin |
| Acessar ou editar Configuracoes | Apenas Super Admin |
| Criar/editar/excluir contas admin | Apenas Super Admin |
| Gerenciar permissoes de funcoes | Apenas Super Admin |

---

## Quando escalar

Entre em contato com seu Super Admin quando precisar:

- Remover permanentemente uma conta de usuario (voce pode banir, mas nao excluir)
- Exportar dados de usuarios para solicitacoes de conformidade ou juridicas
- Alterar configuracoes da plataforma ou flags de funcionalidades
- Conceder acesso admin a um novo membro da equipe
- Excluir uma notificacao enviada por engano
- Lidar com um incidente de seguranca que requer alteracoes no nivel do sistema
