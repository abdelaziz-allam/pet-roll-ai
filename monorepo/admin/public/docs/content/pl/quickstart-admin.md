# Szybki start: Admin

Witamy w Panelu Administracyjnym Petfolioo. Jako Admin masz szeroki dostep operacyjny do zarzadzania uzytkownikami, zwierzetami, trescia i codziennymi dzialaniami platformy. Ten przewodnik obejmuje to, co mozesz robic, Twoj codzienny proces pracy i kiedy eskalowac do Super Admin.

---

## Dostepne strony

| Strona | Dostepne akcje |
|--------|----------------|
| Dashboard | View KPIs platformy i analizy |
| Uzytkownicy aplikacji | View, Create, Edit, Ban |
| Zwierzeta | View, Edit, Delete |
| Kategorie zwierzat | View, Create, Edit, Delete |
| Weryfikacja | View, Approve, Reject |
| Kojarzenie | View, Edit, Delete, Moderate |
| Certyfikaty zdrowia | View, Approve, Reject |
| Analizy szczepien | View, Export |

| Powiadomienia | View, Send |
| Analizy | View, Export |

Strony, ktorych **nie ma** w Twoim panelu bocznym: Uzytkownicy admin, Ustawienia.

---

## Pierwsze kroki po uzyskaniu dostepu

1. **Zaloguj sie i zweryfikuj swoj profil** - Kliknij swoj awatar w prawym gornym rogu, aby potwierdzic poprawnosc imienia i adresu e-mail.
2. **Odkryj Dashboard** - Zrozum aktualny stan platformy: aktywni uzytkownicy, oczekujace weryfikacje, ostatnia aktywnosc.
3. **Sprawdz kolejke Weryfikacji** - Zobacz, czy sa oczekujace weryfikacje hodowcow lub zwierzat wymagajace dzialania.
4. **Przegladaj Uzytkownikow aplikacji** - Posortuj wedlug daty dolaczenia, aby zobaczyc nowe rejestracje i zapoznac sie z baza uzytkownikow.
5. **Przejrzyj Opinie** - Sprawdz, czy sa otwarte skargi uzytkownikow wymagajace odpowiedzi.

## Glowne obowiazki

### Operacje
Jestes glownym operatorem platformy. Przegladanie weryfikacji, moderacja kojarzenia i zarzadzanie uzytkownikami to Twoje podstawowe codzienne zadania. Staraj sie utrzymywac kolejke weryfikacji ponizej 24 godzin.

### Zarzadzanie trescia
Zarzadzasz Blogiem, Kategoriami zwierzat i danymi zwierzat. Upewnij sie, ze posty na blogu sa dokladne, kategorie odzwierciedlaja obslugiwane gatunki, a profile zwierzat zawieraja prawidlowe informacje.

### Wsparcie uzytkownikow
Gdy uzytkownicy aplikacji zglaszaja problemy przez Opinie, jestes odpowiedzialny za udzielenie odpowiedzi. Mozesz edytowac konta uzytkownikow, banowac uzytkownikow naruszajacych zasady i poprawiac dane zwierzat w ich imieniu.

### Zarzadzanie powiadomieniami
Mozesz wysylac powiadomienia ogolnoplatformowe lub ukierunkowane. Uzywaj tego do okien serwisowych, ogloszen o nowych funkcjach lub waznych zmianach w polityce.

---

## Kiedy eskalowac

Skontaktuj sie ze swoim Super Admin, gdy potrzebujesz:

- Trwale usunac konto uzytkownika (mozesz zbanowac, ale nie usunac)
- Wyeksportowac dane uzytkownikow na potrzeby zgodnosci lub zapytan prawnych
- Zmienic ustawienia platformy lub flagi funkcji
- Przyznac dostep admin nowemu czlonkowi zespolu
- Usunac powiadomienie wyslane przez pomylke
- Obsluzyc incydent bezpieczenstwa wymagajacy zmian na poziomie systemu

---

## Uzyskiwanie pomocy

Aby uzyskac wskazowki dotyczace konkretnych modulow, zapoznaj sie z innymi stronami tego podrecznika uzytkownika. W przypadku problemow z dostepem lub uprawnieniami skontaktuj sie z Super Admin swojej organizacji.
