# Szybki start: Moderator

Witamy w Panelu Administracyjnym Petfolioo. Jako Moderator koncentrujesz sie na jakosci tresci i bezpieczenstwie spolecznosci. Przegladasz weryfikacje, moderujesz ogloszenia i dbasz o dokladnosc danych zwierzat. Ten przewodnik obejmuje Twoj dostep, codzienny proces pracy i ograniczenia.

---

## Dostepne strony

| Strona | Dostepne akcje |
|--------|----------------|
| Dashboard | View KPIs platformy |
| Uzytkownicy aplikacji | View, Ban |
| Zwierzeta | View, Edit |
| Kategorie zwierzat | View |
| Weryfikacja | View, Approve, Reject |
| Kojarzenie | View, Moderate |
| Certyfikaty zdrowia | View, Approve, Reject |
| Analizy szczepien | View |
| Opinie | View |
| Blog | View |
| Powiadomienia | View |

Strony, ktorych **nie ma** w Twoim panelu bocznym: Analizy, Uzytkownicy admin, Ustawienia.

---

## Pierwsze kroki po uzyskaniu dostepu

1. **Zaloguj sie i sprawdz swoj profil** - Kliknij swoj awatar, aby potwierdzic poprawnosc danych.
2. **Otworz kolejke Weryfikacji** - To Twoja glowna przestrzen robocza. Zobacz, co czeka na przeglad.
3. **Przegladaj strone Kojarzenia** - Zapoznaj sie z aktywnymi ogloszeniami i dostepnymi narzedziami moderacji.
4. **Odkryj Zwierzeta** - Kliknij kilka profili zwierzat, aby zrozumiec strukture danych i jakie pola mozesz edytowac.
5. **Przejrzyj Dashboard** - Uzyskaj podstawowe zrozumienie poziomu aktywnosci na platformie.

## Codzienna lista kontrolna

- [ ] Sprawdz Dashboard dla szybkiego przegladu kondycji
- [ ] Przetwarzaj kolejke Weryfikacji: przegladaj dokumenty, zatwierdzaj prawdziwych hodowcow, odrzucaj niekompletne lub oszukancze zgloszenia z jasnymi powodami
- [ ] Moderuj ogloszenia Kojarzenia: oznaczaj lub usuwaj nieodpowiednia tresc, weryfikuj dokladnosc ogloszen

- [ ] Sprawdz Certyfikaty zdrowia pod katem oczekujacych przegladow certyfikatow
- [ ] Banuj problematycznych uzytkownikow naruszajacych wytyczne spolecznosci
- [ ] Skanuj Opinie pod katem zgloszen uzytkownikow dotyczacych problemow z trescia (nawet jesli nie mozesz odpowiedziec, mozesz dzialac na podstawie tego, co przeczytasz)

## Glowne obowiazki

### Przeglady weryfikacji
Twoje najwazniejsze zadanie. Hodowcy przesylaja dokumentacje potwierdzajaca ich wiarygodnosc i kwalifikacje. Przegladasz te dokumenty pod katem autentycznosci, kompletnosci i zgodnosci ze standardami platformy. Zatwierdzaj prawidlowe wnioski szybko i odrzucaj oszukancze z jasnym wyjasnieniem.

### Moderacja kojarzenia
Monitoruj ogloszenia na rynku kojarzenia pod katem nieodpowiedniej tresci, wprowadzajacych w blad opisow lub naruszen polityki. Uzyj akcji Moderate, aby oznaczyc lub ukryc problematyczne ogloszenia.

### Jakosc danych zwierzat
Mozesz edytowac profile zwierzat, aby poprawic niedokladne informacje o rasie, naprawic literowki, zaktualizowac stan zdrowia lub usunac nieodpowiednie zdjecia. Utrzymuj rejestr zwierzat dokladnym i wiarygodnym.

### Bezpieczenstwo spolecznosci
Mozesz banowac uzytkownikow naruszajacych wytyczne platformy. Uzywaj tego dla kont spamowych, zachowan obraźliwych lub uzytkownikow, ktorzy wielokrotnie przesylaja oszukancze weryfikacje.

### Przeglad certyfikatow zdrowia
Przegladaj przeslane certyfikaty zdrowia pod katem dokladnosci i zatwierdzaj lub odrzucaj je na podstawie dostarczonej dokumentacji.

## Kiedy eskalowac

Skontaktuj sie z Admin lub Super Admin, gdy potrzebujesz:

- Usunac profil zwierzecia, ktory powinien zostac calkowicie usuniety
- Usunac ogloszenie kojarzenia (mozesz moderowac/oznaczac, ale nie usuwac)
- Odpowiedziec na opinie uzytkownikow wymagajace oficjalnej odpowiedzi
- Wyslac powiadomienie do dotkietych uzytkownikow o akcji moderacyjnej
- Utworzyc lub edytowac post na blogu dotyczacy wytycznych spolecznosci
- Uzyskac dostep do danych analitycznych na potrzeby raportu moderacyjnego

---

## Wskazowki dotyczace skutecznej moderacji

- **Badz konsekwentny** - Stosuj te same standardy do wszystkich przegladow weryfikacji. Dokumentuj swoje uzasadnienie w wiadomosci o odrzuceniu.
- **Dzialaj szybko** - Wnioskodawcy weryfikacji czekaja. Staraj sie przetwarzac zgloszenia w ciagu 24 godzin.
- **W razie watpliwosci, eskaluj** - Jesli przypadek weryfikacji jest niejednoznaczny, oznacz go i popros Admin o druga opinie zamiast dokonywac watpliwego zatwierdzenia.
- **Banuj ostroznie** - Banowanie to powazna akcja. Zarezerwuj je dla wyraznych naruszen polityki, nie dla drobnych problemow.
