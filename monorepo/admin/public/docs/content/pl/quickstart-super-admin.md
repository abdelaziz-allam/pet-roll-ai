# Szybki start: Super Admin

Witamy w Panelu Administracyjnym Petfolioo. Jako Super Admin masz nieograniczony dostep do kazdej strony, akcji i opcji konfiguracyjnej na platformie. Ten przewodnik obejmuje Twoj pierwszy dzien, codzienne procesy pracy i obowiazki.

---

Masz dostep do wszystkiego. Zadne strony nie sa ukryte w Twoim panelu bocznym.

---

## Pierwsze kroki po pierwszym logowaniu

1. **Zweryfikuj swoj profil** - Kliknij swoj awatar w prawym gornym rogu i potwierdz, ze dane konta sa poprawne.
2. **Skonfiguruj ustawienia platformy** - Przejdz do Ustawien i przejrzyj konfiguracje calej platformy (branding, flagi funkcji, domyslne powiadomienia).
3. **Utworz dodatkowe konta admin** - Przejdz do Uzytkownikow admin i utworz konta dla czlonkow zespolu z odpowiednimi rolami.
4. **Ustaw kategorie zwierzat** - Odwiedz Kategorie zwierzat i upewnij sie, ze taksonomia gatunkow i ras jest skonfigurowana dla Twojego regionu.
5. **Przejrzyj Dashboard** - Zapoznaj sie z kartami KPI, abys wiedzial, jak wyglada "norma".

## Glowne obowiazki

### Konfiguracja systemu
Jestes jedyna rola majaca dostep do strony Ustawien. Obejmuje to branding platformy, przelaczniki funkcji, klucze API i szablony powiadomien. Przegladaj je co kwartal lub przy uruchamianiu nowych funkcji.

### Zarzadzanie uzytkownikami
Tylko Ty mozesz tworzyc, edytowac i usuwac konta admin. Przy onboardingu nowych czlonkow zespolu przypisuj minimalna role, jakiej potrzebuja (preferuj Moderator lub Viewer, chyba ze naprawde potrzebuja dostepu Admin).

### Nadzor bezpieczenstwa
- Ogranicz liczbe kont Super Admin do maksymalnie 2-3.
- Co kwartal przegladaj aktywnosc uzytkownikow admin i zawieszaj nieuzywane konta.
- Jestes jedyna rola, ktora moze usuwac uzytkownikow aplikacji i eksportowac dane uzytkownikow, wiec zajmuj sie osobiscie zapytaniami GDPR i danymi.

### Punkt eskalacji
Inne role beda eskalowac do Ciebie, gdy potrzebuja akcji poza swoimi uprawnieniami: usuwanie uzytkownikow, eksportowanie danych, zmiana ustawien lub zarzadzanie kontami admin.

## Wskazowki dotyczace delegowania pracy

| Zadanie | Deleguj do |
|---------|------------|
| Codzienne przegladanie weryfikacji | Admin lub Moderator |
| Moderacja kojarzenia | Admin lub Moderator |
| Korekty danych zwierzat | Admin lub Moderator |
| Wysylanie powiadomien platformy | Admin |
| Monitorowanie i raportowanie analiz | Admin lub Viewer |
| Banowanie problematycznych uzytkownikow | Admin lub Moderator |
| Zarzadzanie trescia bloga | Admin |

Zarezerwuj swoj czas na zadania, ktore tylko Ty mozesz wykonac: zmiany ustawien, zarzadzanie uzytkownikami admin, eksport danych i audyty bezpieczenstwa. Im wiecej pracy operacyjnej delegujesz, tym wiecej masz pojemnosci na nadzor strategiczny.
