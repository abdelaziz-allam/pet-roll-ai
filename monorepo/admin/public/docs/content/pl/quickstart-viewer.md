# Szybki start: Viewer

Witamy w Panelu Administracyjnym Petfolioo. Jako Viewer masz dostep tylko do odczytu do wiekszosci stron platformy. Twoja rola zapewnia wglad w operacje platformy bez mozliwosci modyfikowania jakichkolwiek danych. Ten przewodnik obejmuje to, co mozesz zobaczyc, jak efektywnie korzystac z portalu i jak poprosic o podwyzszony dostep w razie potrzeby.

---

## Dostepne strony

| Strona | Poziom dostepu |
|--------|----------------|
| Dashboard | View KPIs i wykresy analityczne |
| Uzytkownicy aplikacji | View lista uzytkownikow i profile |
| Zwierzeta | View rejestr i profile zwierzat |
| Kategorie zwierzat | View taksonomia kategorii |
| Weryfikacja | View kolejka i status zgloszen |
| Kojarzenie | View ogloszenia na rynku |
| Certyfikaty zdrowia | View rekordy certyfikatow |
| Analizy szczepien | View dane o szczepieniach |
| Opinie | View zgloszenia uzytkownikow |
| Blog | View opublikowane posty |
| Powiadomienia | View wyslane powiadomienia |
| Analizy | View wykresy i metryki |

Strony, ktorych **nie ma** w Twoim panelu bocznym: Uzytkownicy admin, Ustawienia.

---

## Co "Tylko podglad" oznacza w praktyce

Twoj interfejs jest uproszczony w porownaniu z innymi rolami:

| Element UI | Co widzisz |
|------------|------------|
| Przyciski Utworz/Dodaj | Ukryte - niewidoczne nigdzie |
| Przyciski Edytuj | Ukryte - wiersze tabeli nie sa klikalne do edycji |
| Opcje usuwania | Ukryte - brak menu akcji z destrukcyjnymi opcjami |
| Przyciski Approve/Reject | Ukryte - status weryfikacji wyswietlany jako tekst tylko do odczytu |
| Przycisk Send Notification | Ukryty |
| Przyciski Export | Ukryte |
| Przyciski Ban/Unban | Ukryte |

Widzisz te same dane co inne role, ale interfejs usuwa wszystkie kontrolki akcji. Oznacza to, ze nie mozesz przypadkowo niczego zmodyfikowac. Tabele, wykresy, widoki szczegolowe i wskazniki statusu wyswietlaja sie normalnie.

---

## Pierwsze kroki po uzyskaniu dostepu

1. **Zaloguj sie i zweryfikuj swoj profil** - Kliknij swoj awatar, aby potwierdzic dane konta.
2. **Odkryj Dashboard** - To Twoja baza. Przeanalizuj karty KPI i wykresy analityczne, aby zrozumiec kondycje platformy na pierwszy rzut oka.
3. **Odwiedz Analizy** - Przejrzyj trendy zaangazowania, metryki wzrostu i wzorce uzytkowania platformy.
4. **Przegladaj Uzytkownikow aplikacji i Zwierzeta** - Zapoznaj sie z dostepnymi danymi na potrzeby raportowania.
5. **Sprawdz Weryfikacje** - Zrozum status kolejki i wskaznik zatwierdzenia, aby ocenic obciazenie operacyjne.

## Glowne obowiazki

### Nadzor
Twoja glowna wartosc to swiadomy nadzor. Mozesz widziec pelny obraz operacji platformy bez koniecznosci podejmowania dzialania. Wykorzystaj to do identyfikowania trendow, wczesnego wykrywania potencjalnych problemow i informowania interesariuszy.

### Raportowanie
Chociaz nie mozesz eksportowac danych bezposrednio z portalu, mozesz wykorzystac to, co widzisz, do przygotowywania raportow zewnetrznie. Strony Dashboard i Analizy dostarczaja metryk najczesciej potrzebnych do aktualizacji dla interesariuszy.

### Monitorowanie
Obserwuj nietypowe wzorce: nagle spadki zatwierdzeni weryfikacji, skoki w banowaniu uzytkownikow lub malejace metryki zaangazowania. Gdy zauwazsz cos niepokojacego, zglos to Admin lub Super Admin, ktory moze to zbadac i podjac dzialania.

### Widocznosc dla interesariuszy
Jesli jestes interesariuszem biznesowym, inwestorem lub partnerem, rola Viewer daje Ci przejrzystosc operacji platformy bez koniecznosci przygotowywania przez zespol oddzielnych raportow.

---

## Przygotowywanie raportow z dostepem tylko do odczytu

Poniewaz nie mozesz eksportowac danych bezposrednio, oto skuteczne podejscia:

1. **Zrzuty ekranu** - Przechwytuj wykresy Dashboard i Analiz do prezentacji.
2. **Reczne notatki** - Zapisuj kluczowe metryki z kart KPI podczas codziennego przegladu.
3. **Prosby o eksport** - Popros Admin lub Super Admin o wyeksportowanie danych potrzebnych do glabszej analizy.
4. **Zaplanowane przeglady** - Ustal cykliczny czas przegladu portalu i notowania zmian z tygodnia na tydzien.

---

## Jak poprosic o podwyzszony dostep

Jesli Twoje obowiazki sie zmienia i potrzebujesz mozliwosci podejmowania dzialania (zatwierdzanie weryfikacji, moderowanie tresci, zarzadzanie uzytkownikami), postepuj zgodnie z tym procesem:

1. Zidentyfikuj, jakich konkretnych akcji potrzebujesz i dlaczego.
2. Skontaktuj sie z Super Admin swojej organizacji ze swoim zapytaniem.
3. Okresls, czy potrzebujesz podwyzszenia roli (do Moderator lub Admin), czy tylko konkretnych dodatkowych uprawnien.
4. Super Admin moze dostosowasc Twoje uprawnienia bez zmiany etykiety roli, jesli potrzebnych jest tylko kilka dodatkowych akcji.

---

## Uzyskiwanie pomocy

W przypadku pytan dotyczacych tego, co widzisz w portalu, zapoznaj sie ze stronami dotyczacymi konkretnych modulow w tym podreczniku uzytkownika. W przypadku prosb o dostep lub watpliwosci dotyczacych danych platformy skontaktuj sie z Admin lub Super Admin.
