# Snabbstart: Admin

Valkomna till Petfolioo Admin Portal. Som Admin har du bred operativ tillgang for att hantera anvandare, husdjur, innehall och dagliga plattformsaktiviteter. Denna guide tar upp vad du kan gora, ditt dagliga arbetsflode och nar du bor eskalera till en Super Admin.

---

## Sidor tillgangliga for dig

| Sida | Tillgangliga atgarder |
|------|-------------------|
| Dashboard | View plattformens KPI:er och analyser |
| Appanvandare | View, Create, Edit, Ban |
| Husdjur | View, Edit, Delete |
| Husdjurskategorier | View, Create, Edit, Delete |
| Verifiering | View, Approve, Reject |
| Parning | View, Edit, Delete, Moderate |
| Halsointyg | View, Approve, Reject |

| Notifikationer | View, Send |
| Analys | View, Export |

Sidor som **inte** finns i din sidopanel: Adminanvandare, Installningar.

---

## Forsta stegen efter att du fatt tillgang

1. **Logga in och verifiera din profil** - Klicka pa din avatar uppe till hoger for att bekrafta att ditt namn och din e-post ar korrekta.
2. **Utforska Dashboard** - Forsta plattformens nuvarande tillstand: aktiva anvandare, vantande verifieringar, senaste aktiviteten.
3. **Kontrollera verifieringskon** - Se om det finns vantande uppfodar- eller husdjursverifieringar som vantar pa atgard.
4. **Bladdra bland Appanvandare** - Sortera efter senaste registreringsdatum for att se nya registreringar och bekanta dig med anvandarbasen.
5. **Granska Feedback** - Kontrollera om det finns oppna anvandarklagomal som behover ett svar.

---

## Daglig arbetsflodeschecklista

- [ ] Oppna Dashboard och granska KPI-korten for nagot ovanligt
- [ ] Behandla vantande arenden i verifieringskon (godkanna eller avvisa med motivering)
- [ ] Kontrollera Parningslistningar for nya eller flaggade poster som kraver moderering
- [ ] Granska Feedback-inskickningar och svara pa brastande arenden
- [ ] Overvaka Appanvandare for konton som behover bannas eller utredas
- [ ] Kontrollera Halsointyg for vantande certifieringsgranskningar
- [ ] Skicka plattformsnotifikationer om det finns meddelanden eller underhallsfonster
- [ ] Granska Analys for engagemangstrender och exportera rapporter vid behov

---

## Viktiga ansvarsomraden

### Drift
Du ar den primara operatoren av plattformen. Verifieringsgranskningar, parningsmoderering och anvandarhantering ar dina centrala dagliga uppgifter. Hall verifieringskon under 24 timmar gammal nar det ar mojligt.

### Innehallshantering
Du hanterar Bloggen, Husdjurskategorier och husdjursdata. Sakerstall att blogginlagg ar korrekta, att kategorier aterspeglar de stodda arterna och att husdjursprofiler har korrekt information.

### Anvandarsupport
Nar appanvandare rapporterar problem genom Feedback ar du ansvarig for att svara. Du kan redigera anvandarkonton, banna missbrukande anvandare och ratta husdjursdata pa deras vagnar.

### Notifikationshantering
Du kan skicka plattformsovergripande eller riktade notifikationer. Anvand detta for underhallsfonster, funktionsmeddelanden eller viktiga policyandring.

## Vad du inte kan gora

| Atgard | Vem kan |
|--------|---------|
| Delete appanvandare | Endast Super Admin |
| Export anvandardata | Endast Super Admin |
| Delete notifikationer | Endast Super Admin |
| Atkomst eller Edit Installningar | Endast Super Admin |
| Create/Edit/Delete adminkonton | Endast Super Admin |
| Manage Permissions | Endast Super Admin |

---

## Nar du bor eskalera

Kontakta din Super Admin nar du behover:

- Ta bort ett anvandarkonto permanent (du kan banna, men inte radera)
- Exportera anvandardata for efterlevnads- eller juridiska forfragan
- Andra plattformsinstellningar eller funktionsflaggor
- Ge admin-atkomst till en ny teammedlem
- Radera en notifikation som skickades av misstag
- Hantera en sakerhetsincident som kraver andringar pa systemniva
