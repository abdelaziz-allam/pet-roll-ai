# Snabbstart: Super Admin

Valkomna till Petfolioo Admin Portal. Som Super Admin har du obegransad tillgang till varje sida, aktion och konfigurationsalternativ pa plattformen. Denna guide tar upp din forsta dag, dagliga arbetsfloden och ansvarsomraden.

Du har tillgang till allt. Inga sidor ar dolda fran din sidopanel.

---

## Forsta stegen efter initial inloggning

1. **Verifiera din profil** - Klicka pa din avatar uppe till hoger och bekrafta att dina kontouppgifter ar korrekta.
2. **Konfigurera plattformsinstellningar** - Navigera till Installningar och granska plattformsovergripande konfiguration (varumarke, funktionsflaggor, standardnotifikationer).
3. **Skapa ytterligare adminkonton** - Ga till Adminanvandare och skapa konton for dina teammedlemmar med lampliga roller.
4. **Lagg till husdjurskategorier** - Besok Husdjurskategorier och sakerstall att taxonomin for arter och raser ar konfigurerad for din region.
5. **Granska Dashboard** - Bekanta dig med KPI-korten sa att du vet hur "normalt" ser ut.

## Viktiga ansvarsomraden

### Systemkonfiguration
Du ar den enda rollen som kan komma at sidan Installningar. Detta inkluderar plattformens varumarke, funktionsflaggor, API-nycklar och notifikationsmallar. Granska dessa kvartalsvis eller vid lansering av nya funktioner.

### Anvandarhantering
Endast du kan skapa, redigera och radera adminkonton. Nar du introducerar nya teammedlemmar, tilldela den lagsta rollen de behover (foredra Moderator eller Viewer om de inte genuint behover Admin-atkomst).

### Sakerhetsovervakning
- Hall antalet Super Admin-konton till maximalt 2-3.
- Granska adminanvandaraktivitet kvartalsvis och inaktivera oanvanda konton.
- Du ar den enda rollen som kan radera appanvandare och exportera anvandardata, sa hantera GDPR- och dataforfragan personligen.

### Eskaleringspunkt
Andra roller kommer att eskalera till dig nar de behover atgarder utanfor sina behorigeter: radera anvandare, exportera data, andra installningar eller hantera adminkonton.

## Tips for att delegera arbete

| Uppgift | Delegera till |
|------|-------------|
| Dagliga verifieringsgranskningar | Admin eller Moderator |
| Parningsmoderering | Admin eller Moderator |
| Husdjursdatakorrigeringar | Admin eller Moderator |
| Skicka plattformsnotifikationer | Admin |
| Analysovervakning och rapportering | Admin eller Viewer |
| Banna problematiska anvandare | Admin eller Moderator |
| Blogginnehallshantering | Admin |

Reservera din tid for uppgifter som bara du kan utfora: installningsandringar, adminanvandarhantering, dataexporter och sakerhetsgranskningar. Ju mer du delegerar operativt arbete, desto mer kapacitet har du for strategisk overvakning.
