# Snabbstart: Moderator

Valkomna till Petfolioo Admin Portal. Som Moderator ar ditt fokus innehallskvalitet och communitysakerhet. Du granskar verifieringar, modererar listningar och sakerstallar att husdjursdata ar korrekt. Denna guide tar upp din tillgang, dagliga arbetsflode och granser.

---

## Sidor tillgangliga for dig

| Sida | Tillgangliga atgarder |
|------|-------------------|
| Dashboard | View plattformens KPI:er |
| Appanvandare | View, Ban |
| Husdjur | View, Edit |
| Husdjurskategorier | View |
| Verifiering | View, Approve, Reject |
| Parning | View, Moderate |
| Halsointyg | View, Approve, Reject |
| Vaccinationsanalys | View |
| Feedback | View |
| Blogg | View |
| Notifikationer | View |

Sidor som **inte** finns i din sidopanel: Analys, Adminanvandare, Installningar.

---

## Forsta stegen efter att du fatt tillgang

1. **Logga in och kontrollera din profil** - Klicka pa din avatar for att bekrafta att dina uppgifter ar korrekta.
2. **Oppna verifieringskon** - Detta ar din primara arbetsyta. Se vad som vantar pa granskning.
3. **Bladdra pa Parningssidan** - Bekanta dig med aktiva listningar och de modereringsverktyg som finns tillgangliga.
4. **Utforska Husdjur** - Klicka in pa nagra husdjursprofiler for att forsta datastrukturen och vilka falt du kan redigera.
5. **Granska Dashboard** - Fa en grundforstaelse for plattformens aktivitetsniva.

---

## Daglig arbetsflodeschecklista

- [ ] Kontrollera Dashboard for en snabb halsooversikt
- [ ] Behandla verifieringskon: granska dokument, godkanna legitima uppfodare, avvisa ofullstandiga eller bedragliga inskickningar med tydlig motivering
- [ ] Moderera Parningslistningar: flagga eller ta bort olampligt innehall, verifiera listningens korrekthet
- [ ] Granska Husdjur for rapporterade eller flaggade profiler och ratta felaktig data
- [ ] Kontrollera Halsointyg for vantande certifieringsgranskningar
- [ ] Ban problematiska anvandare som bryter mot communityns riktlinjer
- [ ] Skanna Feedback for anvandarrapporter om innehallsproblem (aven om du inte kan svara kan du agera pa det du laser)

## Viktiga ansvarsomraden

### Verifieringsgranskningar
Din viktigaste uppgift. Uppfodare skickar in dokumentation for att bevisa sina meriter och legitimitet. Du granskar dessa dokument for akthet, fullstandighet och efterlevnad av plattformens standarder. Godkann legitima ansokan snabbt och avvisa bedragliga med tydlig forklaring.

### Parningsmoderering
Overvaka parningsmarknadens listningar for olampligt innehall, vilseledande beskrivningar eller policyovertradelr. Anvand Moderate-atgarder for att flagga eller dolja problematiska listningar.

### Husdjursdatakvalitet
Du kan redigera husdjursprofiler for att ratta felaktig rasinformation, fixa stavfel, uppdatera halsostatus eller ta bort olampliga bilder. Hall husdjursregistret korrekt och palitligt.

### Communitysakerhet
Du kan banna anvandare som bryter mot plattformens riktlinjer. Anvand detta for spamkonton, missbrukande beteende eller anvandare som upprepade ganger skickar in bedragliga verifieringar.

### Halsocertifieringsgranskning
Granska inskickade halsocertifieringar for korrekthet och godkann eller avvisa dem baserat pa den medfoljande dokumentationen.

## Nar du bor eskalera

Kontakta en Admin eller Super Admin nar du behover:

- Radera en husdjursprofil som bor tas bort helt
- Ta bort en parningslistning (du kan moderera/flagga, men inte radera)
- Svara pa anvandarfeedback som kraver ett officiellt svar
- Skicka en notifikation till beorda anvandare om en modereringsatgard
- Skapa eller redigera ett blogginlagg om communityns riktlinjer
- Fa tillgang till analysdata for en modereringsrapport

---

## Tips for effektiv moderering

- **Var konsekvent** - Tillampa samma standarder pa alla verifieringsgranskningar. Dokumentera din motivering i avvisningsmeddelandet.
- **Agera snabbt** - Verifieringssokan vantar. Forsok behandla inskickningar inom 24 timmar.
- **Eskalera vid osaker** - Om ett verifieringsarende ar tvetydigt, flagga det och fraga en Admin om en andra asikt istallet for att gora ett tveksamt godkannande.
- **Banna med forsiktighet** - Bannning ar en allvarlig atgard. Reservera den for tydliga policyovertradelr, inte smarre problem.
