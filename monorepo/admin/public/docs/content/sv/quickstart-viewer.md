# Snabbstart: Viewer

Valkomna till Petfolioo Admin Portal. Som Viewer har du skrivskyddad tillgang till de flesta plattformssidorna. Din roll ger insyn i plattformens drift utan mojlighet att andra nagon data. Denna guide tar upp vad du kan se, hur du anvander portalen effektivt och hur du begur utokad tillgang vid behov.

---

## Sidor tillgangliga for dig

| Sida | Tillgangsniva |
|------|--------------|
| Dashboard | View KPI:er och analysdiagram |
| Appanvandare | View anvandarlista och profiler |
| Husdjur | View husdjursregister och profiler |
| Husdjurskategorier | View kategoritaxonomi |
| Verifiering | View ko och inskickningsstatus |
| Parning | View marknadsplatslistningar |
| Halsointyg | View certifieringsposter |
| Vaccinationsanalys | View vaccinationsdata |
| Feedback | View anvandarinschickningar |
| Blogg | View publicerade inlagg |
| Notifikationer | View skickade notifikationer |
| Analys | View diagram och matetal |

Sidor som **inte** finns i din sidopanel: Adminanvandare, Installningar.

---

## Vad "enbart visning" innebar i praktiken

Ditt granssnitt ar forenklat jamfort med andra roller:

| UI-element | Vad du ser |
|------------|--------------|
| Create/Add-knappar | Dolda - inte synliga nagontstans |
| Edit-knappar | Dolda - tabellrader ar inte klickbara for redigering |
| Delete-alternativ | Dolda - inga atgardsmenyer med destruktiva alternativ |
| Approve/Reject-knappar | Dolda - verifieringsstatus visas som skrivskyddad text |
| Send Notification-knapp | Dold |
| Export-knappar | Dolda |
| Ban/Unban-knappar | Dolda |

Du ser samma data som andra roller, men granssnittet tar bort alla atgardskontroller. Detta innebar att du inte kan andra nagonting av misstag. Tabeller, diagram, detaljvyer och statusindikatorer visas normalt.

---

## Forsta stegen efter att du fatt tillgang

1. **Logga in och verifiera din profil** - Klicka pa din avatar for att bekrafta dina kontouppgifter.
2. **Utforska Dashboard** - Detta ar din hemvy. Studera KPI-korten och analysdiagrammen for att forsta plattformens halsa overblick.
3. **Besok Analys** - Granska engagemangstrender, tillvaxtmatetal och plattformsanvandningsmonstre.
4. **Bladdra bland Appanvandare och Husdjur** - Bekanta dig med den data som finns tillganglig for dina rapporteringsbehov.
5. **Kontrollera Verifiering** - Forsta kostatus och godkannandegrad for att bedoma den operativa belastningen.

## Viktiga ansvarsomraden

### Overvakning
Ditt primara varde ar informerad overvakning. Du kan se hela bilden av plattformens drift utan att behova vidta atgarder. Anvand detta for att identifiera trender, upptacka potentiella problem tidigt och halla intressenter informerade.

### Rapportering
Aven om du inte kan exportera data direkt fran portalen kan du anvanda det du ser for att forbereda rapporter externt. Sidorna Dashboard och Analys tillhandahaller de matetal som oftast behovs for intressentuppdateringar.

### Bevakning
Bevaka ovanliga monster: plotsliga fall i verifieringsgodkannanden, toppar i anvandarbannningar eller sjunkande engagemangsmatetal. Nar du upptacker nagot oroande, ta upp det med en Admin eller Super Admin som kan utreda och agera.

### Intressentinsyn
Om du ar en affarsintressent, investerare eller partner ger Viewer-rollen dig transparens i plattformens drift utan att teamet behover forbereda separata rapporter for dig.

---

## Forbereda rapporter med visningstillgang

Eftersom du inte kan exportera data direkt, har ar effektiva tillvagagangssatt:

1. **Skarmdumpar** - Ta bilder av Dashboard- och analysdiagram for presentationer.
2. **Manuella anteckningar** - Notera nyckelmatetal fran KPI-korten under din dagliga granskning.
3. **Begar exporter** - Be en Admin eller Super Admin att exportera data du behover for djupare analys.
4. **Schemalagda granskningar** - Satt en aterkommande tid for att granska portalen och notera forandringar vecka for vecka.

---

## Hur du begar utokad tillgang

Om dina ansvarsomraden andras och du behover mojlighet att vidta atgarder (godkanna verifieringar, moderera innehall, hantera anvandare), folj denna process:

1. Identifiera vilka specifika atgarder du behover och varfor.
2. Kontakta din organisations Super Admin med din forfragan.
3. Specificera om du behover en rolluppgradering (till Moderator eller Admin) eller bara specifika ytterligare behorigeter.
4. Super Admin kan anpassa dina behorigeter utan att andra din rolletikett om bara nagra fa extra atgarder behovs.
